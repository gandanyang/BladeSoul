# ── 与既有 12 张「人设图」的区别（为什么还要再做一套）────────────
#   ComfyUI 输出目录里已有 aya_a~f / aya2_a~f 共 12 张（2026-09-12 22:4x）。
#   但它们全部是**人设图**：半身像、场景（诊伤 / 雨巷）、面部特写。
#   **没有一张是"各方位"**——而 3D 管线（T35 本地 Hunyuan3D / T36 Tripo）
#   要的是**同一角色、同光照、同姿势下的多角度**，否则背面只能靠猜。
#   （魔骸足兵就是这么吃过亏的：v2 六张全是正面，出来的模型背面是编的。）
#
# ── 六条规格对照（12 §6）────────────────────────────────
#   1 主体与背景强明暗对比 ............ ✓ 见下面的「★ 一处有意的偏离」
#   2 背景纯色、无地面无阴影 .......... ✓ 明确写了"没有地面、没有墙壁、没有影子、没有投影"
#   3 无薄片悬空结构 .................. ✓ 无笠无薄纱；低髻用布条系紧、不做飘带
#   4 无伸出画面的细长结构 ............ ✓ 三件腰挂明确"收在身体轮廓之内、不向外突出"；不拿木箱
#   5 A 字姿、四肢不遮躯干 ............ ✓ a~e 全是 A 字姿
#   6 分辨率 ≥1024、主体占 80%+ ....... ✓ 1024x1536，占画面高度 90%
#
# ── ★ 一处有意的偏离，必须记录 ────────────────────────────────
#   12 §6 写的是「浅色/纯白背景」。魔骸是**深色**主体，纯白背景对比最好；
#   但绫是**浅色**主体（旧白亚麻 + 苔绿），**纯白背景会把她的剪影吃掉**——
#   这正好违了第 1 条规格的本意（明暗对比是为了让深度估得准）。
#   所以这里改用**中浅灰蓝单色背景**：比她暗、比纯黑亮，两个方向都有轮廓对比。
#   背景依旧是**纯色、无场景、无阴影**，不会被烘进网格。
#
