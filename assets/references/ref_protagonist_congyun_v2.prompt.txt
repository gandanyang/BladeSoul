#   1. **薄片悬空结构一箩筐** —— 违反 12 §6 第 3 条。
#      后颈那条布带垂到肩背、袍摆与裤腿挂着大片长条破布、斗篷边缘稀碎。
#      体素化时这些最容易糊掉或穿洞（阵笠就是这么栽的）。**要送 3D 就必须先收掉。**

#      出图是**棱角分明的紫黑晶体／尖刺**，而且**盖满了整条小臂**（设定只到手背包到小臂中段）。
#      它是本作第一视觉标识，建议这一处单独重出。
#   3. **袍长偏长** —— 设定下摆到胯下，出图是**到小腿的长袍**，
#      剪影因此偏"长衫侠客"，比设定飘逸一档。
#   4. **肤色偏白偏灰** —— 设定是低饱和略脏黄褐 #B99A80，出图偏冷白，少了"吃过苦"的脏感。
#   5. **比例偏修长** —— 看起来比设定的 7.2 头身更接近英雄比例；
#      三张里正面那张尤其明显（腿偏长）。
