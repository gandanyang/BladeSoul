# ── 为什么这样写（下次出别的 3D 输入图照这个套路）──────
#
# 这条提示词跟"人设图"的写法有三处不同，都是为了**喂 3D 生成**：
#   1. A 字站姿 + 四肢不遮躯干  → 自动绑骨与体素化都需要肢体分离，
#      否则 3D 模型会把手臂和躯干糊成一块
#   2. 中性背景、无场景          → 背景会被一起体素化进模型
#   3. 材质粗糙度彼此分明        → 生成端要靠明暗区分"这块是甲、这块是布"
#
# 另外两条是颜色纪律（10 §1）：整幅图只有黑/暗灰/铁色/血红，
# 且血红只出现在眼窝与伤口 —— 这样主角（低饱和蓝灰）和魔骸（黑红）能一眼分开。
