# ── 枪兵与足兵的三处不同（10 §2.2）──────────────────────
#   1 可读残迹：**完整的长枪**（枪身完好——枪不是它身体的一部分）＋ 破损的具足
#   2 体型：**瘦长、站得比别的魔骸直**——它还记得枪兵的姿势（全魔骸里最"人"的一个）
#   3 危险信号：长枪尖端有微弱的红光拖尾（对应 02 §3「危」的高音预警）
#
# ── 六张各改一个变量（便于看出哪条规格在起作用）────────
#   a  浅灰背景 ＋ 深铁灰具足 ＋ 挺直瘦长     ← 基线
#   b  纯白背景 ＋ 深铁灰具足 ＋ 挺直瘦长     ← ★ 主用（对比度最高）
#   c  纯白背景 ＋ **纯黑**具足 ＋ 挺直瘦长    ← 对照 b：只换甲色（黑会不会糊成一团）
#   d  同 b，换 seed                          ← 测稳定性
#   e  同 b ＋ 略佝偻                         ← 对照 b：只换体态（"站直"该做到什么程度）
#   f  **长枪单独一张**                        ← 12 §6 的建议：武器拆件生成，引擎里摆
#
# ── 生成参数 ──────────────────────────────────────────
#   模型    Z-Image Turbo（cfg=1 蒸馏，不填负面提示词）
#   尺寸    1024 x 1536
#   样式    --style none
#   复现    python zimage_run.py --jobs-file <本文件> --num 1 --style none --tag yari1
#   （脚本在 G:\BaiduSyncdisk\comfyui-workflow-skill\zimage_run.py）
#
# ── 为什么长枪要拆件（12 §6 第 4 条）──────────────────
#   枪是**细长结构**：竖直持枪会比人还高（必然伸出画面，违反第 6 条"主体占 80%+"），
#   斜握又必定伸出画面（违反第 4 条）。所以按 12 §6 的处理办法：**人单独生成，枪单独生成**，
#   在引擎里作为独立部件挂上去——顺便还能换挂点、做 LOD。
