# 鬼刃 · ONIBLADE

> 用 Godot 4.7 做的 3D 和风剑戟动作游戏。战斗内核参考《只狼》的弹开/体干体系，
> 剧情推进与"一闪"体系参考《鬼武者》系列（含 2026 年《鬼武者 剑之道》的公开设定）。
> 目标：**打得爽、有深度、但绝不劝退手残玩家。**

---

## 一句话定位

一个以「弹开—拼刀—一闪」为爽点核心的 3D 剑戟小游戏。
玩家扮演获得「噬魂笼手」的流浪剑客，在魔骸横行的战国末期一路斩向第六天魔王。

**发布口径**：1.0 = 序章 + 第一章 + 1 个 BOSS（15~20 分钟，完整战斗系统）。
3.5~4 小时的完整流程属于 1.0 之后的内容扩充，视 DEMO 反馈再决定。
理由见 [08-顶层设计评审](docs/08-顶层设计评审.md) §3 P0-2 与 [06-开发路线图](docs/06-开发路线图.md) §0 口径修订。

## 核心机制（本项目的卖点，全部必须有手感）

| 机制 | 说明 | 玩家价值 |
|---|---|---|
| **格挡** | 按住防御，正面 ±70° 内挡下攻击，掉体干不掉血 | 兜底手段，手残也能活 |
| **弹开** | 防御后极短时间内被命中 → 零体干、大量削敌人态 | 主要成长曲线 |
| **拼刀** | 双方攻击判定同帧相撞 → 火花、顿帧、双双后滑 | 对攻的戏剧性 |
| **真一闪** | 敌人命中前精确窗口内按**攻击键** → 秒杀杂兵 | 高风险高回报 |
| **弹一闪** | 弹开成功后立刻按攻击 → 强化斩 | 弹开的奖励闭环 |
| **避一闪** | 完美闪避后立刻按攻击 → 强化斩 | 给不爱防御的人一条路 |
| **连锁一闪** | 一闪命中后的窗口内再按攻击，瞬移到下一个敌人 | 割草的爽感 |
| **体干/忍杀** | 体干打满 → 处决 | 战术目标 |

## 难度哲学（最重要的一条）

**三条独立可行的通关路径，任何一条都能打完，只是效率不同：**

1. **技巧流** — 弹开 + 一闪，快速、华丽、高风险
2. **基础流** — 闪避 + 普攻 + 格挡，慢但稳，不需要任何精准操作
3. **资源流** — 魂/鬼力/道具，靠收集和消耗品硬磨

再叠加**隐式动态难度（DDA）**：死多了系统悄悄放水，但从不告诉玩家。
详见 [05-难度曲线与可及性设计](docs/05-难度曲线与可及性设计.md)。

## 技术栈

- **引擎**：Godot 4.7.1 stable **mono**，路径 `G:\Godot_v4.7.1-stable_mono_win64`
- **语言**：**C# / .NET 8**（全项目统一，不混用 GDScript）
  - 已验证：dotnet SDK `8.0.424`，`Godot.NET.Sdk 4.7.1` 已缓存
  - NuGet 源 `GodotLocal` 已全局注册，可离线还原
- **物理**：固定 60Hz physics tick，所有战斗判定在 `_PhysicsProcess` 中按帧结算
- **渲染**：Forward+，目标 1080p / 60fps，同屏敌人上限 8

### 目录三层铁律（详见 00 文档 §2.1）

```
scenes/  只放结构     data/  只放数值（.tres，改这里不用编译）
src/     只放逻辑     tests/ 纯逻辑单测（脱离引擎跑）    assets/ 原始素材
```

### C# 带来的两个铁律

C# 的代价是**改代码必须重新编译，不能像 GDScript 那样热重载**。
对本项目（调参占 40% 工时）这是真实风险，所以定两条硬规则：

1. **所有可调数值必须放在 Resource (.tres) 里，不许写死在 C# 常量中。**
   弹开窗口、伤害、体干、前摇后摇、敌人 AI 参数、难度系数——全部是
   `[GlobalClass]` + `[Export]` 的自定义 Resource。改数值只需在编辑器里拖滑条，
   **零编译、零重启**。C# 只负责逻辑，不负责数值。
2. **纯逻辑与 Godot 节点分离。** 战斗裁决（弹开/拼刀/一闪的优先级判定）
   写成不依赖场景树的纯函数，这样可以脱离引擎跑单元测试，
   也不必每次调优先级都开游戏验证。

## 范围界定（先说清楚不做什么）

**做：**
- 3 个可玩关卡 + 2 个完整 BOSS + 1 个精英怪类型的**垂直切片**先跑通
- 1 套打磨到位的近战手感（格挡/弹开/拼刀/一闪）
- 1 个训练场（道场）用来教学和调参
- 1 个挑战模式（BOSS 连战 / 限时 / 无伤），复用已有资产，性价比极高

**不做（或推迟到 1.0 之后）：**
- 开放世界 / 大地图探索
- 多武器流派（MVP 只有一把太刀 + 鬼力）
- 联机 / PVP
- 全程配音、过场动画（用图文对话 + 字幕 + 黑屏字卡代替）
- 写实级美术（用免费/低模资产占位，手感优先于画面）
