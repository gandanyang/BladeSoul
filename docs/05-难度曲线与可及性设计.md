# 05 · 难度曲线与可及性设计

> 这份文档回答项目的核心诉求：**「足够有挑战性，但不至于劝退手残玩家」**。
> 答案是两套机制叠加：**显式难度选项**（玩家自己选）+ **隐式动态难度 DDA**（系统偷偷帮忙）。

---

## 1. 设计立场

先说清楚一个容易被搞错的事：

> **降低难度 ≠ 降低挑战性。**
> 我们要降的是"操作门槛"，不是"思考门槛"。

具体表现：
- 剑客难度下，弹开窗从 9 帧放宽到 12 帧 —— 操作门槛降了
- 但敌人依然会连段、依然会用危攻击、依然需要你判断"该闪还是该弹" —— 思考门槛没降
- **手残玩家依然会感到紧张和成就感，只是不需要 100ms 的反应速度**

对比一下错误的做法（我们要避免的）：
- ❌ 把敌人血量砍一半 → 战斗变长变无聊，成就感也没了
- ❌ 给玩家 10 条命 → 死不再是"我差一点"，而是"随便"
- ❌ 加自动战斗 → 玩家变成观众

## 2. 四档难度

四档难度就是 `data/difficulty/` 下的 4 个 `.tres`（`DifficultyProfile` 资源）。
**全部数值可调，不加一行代码。**

| 参数 | 修罗 | **武士（默认）** | 剑客 | 见習 |
|---|---|---|---|---|
| 弹开窗 | 6 帧 (100ms) | **9 帧 (150ms)** | 12 帧 (200ms) | 16 帧 (267ms) |
| 一闪窗 | 4 帧 | **6 帧** | 8 帧 | 10 帧 |
| 闪避无敌帧 | 7 | **8** | 9 | 11 |
| 输入缓冲 | 6 帧 | **8 帧** | 10 帧 | 12 帧 |
| 敌人前摇加长 | 0 | **0** | +2 帧 | +4 帧 |
| 敌人血量倍率 | 1.15 | **1.0** | 0.9 | 0.75 |
| 敌人攻击间隔倍率 | 0.9 | **1.0** | 1.12 | 1.3 |
| 敌人反应延迟加成 | 0 | **0** | +4 帧 | +8 帧 |
| 玩家体干恢复倍率 | 0.85 | **1.0** | 1.2 | 1.5 |
| 玩家受伤倍率 | 1.2 | **1.0** | 0.85 | 0.65 |
| 复活次数 | 1 | **1** | 2 | 3 |
| 危攻击提示 | 仅音效 | **音效 + 图标** | + 视觉预警圈 | + 慢镜 0.15s |
| 半自动防御 | ✗ | ✗ | ✗ | 可选 ✓ |

### 关键说明

- **武士是默认**，也是所有平衡工作的基准。做平衡只调武士，其他三档按上表的倍率派生
- **修罗不是"标准"，是挑战模式**。它不该是玩家的第一选择，放在选项列表最后
- **见習（みごと / 见事）**：名字刻意不用"简单"这种带贬义的词，
  用「见习」——"我还在见习"。玩家选它不会有被羞辱感

### 难度可随时切换

**允许在设置里随时改难度，不需要重开存档。**
理由：动作游戏卡关时的挫败感是即时的，强制重开只会让人退款。
切换时给一句非评判性的提示：

> 「已切换至剑客难度。战斗节奏会稍有不同。」

不写"你确定要降低难度吗？这会影响成就"——**任何暗示玩家不行的话都不许出现**。

## 3. 隐式动态难度（DDA）

### 设计原则

1. **绝不告知玩家**：不显示"已为你降低难度"，不弹提示，不改 UI
2. **可关闭**：设置里有一项「自适应难度」开关，默认开启
3. **只帮忙，不代打**：只调整"容错"和"节奏"，不调整"玩家输出"
4. **有上限**：最多帮忙到某个程度就停，避免战斗变得无聊

### 触发条件与效果

| 触发条件 | 悄悄调整 | 上限 |
|---|---|---|
| 同一 BOSS 连续死亡 ≥ 3 次 | 敌人血量 −8%/次 | 最多 −25% |
| 同一 BOSS 连续死亡 ≥ 3 次 | 敌人攻击间隔 +0.1s/次 | 最多 +0.4s |
| 同一 BOSS 连续死亡 ≥ 3 次 | 敌人前摇 +1 帧/次 | 最多 +4 帧 |
| 弹开成功率 < 25% 且单场战斗 > 150s | 弹开窗 +2 帧 | 最多 +4 帧 |
| 单场战斗被忍杀 ≥ 2 次 | 敌人反应延迟 +4 帧 | 最多 +8 帧 |
| 单场战斗内体干破防 ≥ 3 次 | 玩家体干消耗 −15% | 最多 −30% |
| **连续 2 场战斗无伤** | 敌人攻击欲望 +0.1 | 最多 +0.3（反向回调） |

### 重置条件

- 打赢这个 BOSS → 该 BOSS 的 DDA 累积清零
- 玩家在设置里关掉自适应 → 全部清零
- **换难度档 → 全部清零**（避免"新手难度 + DDA 加成"过度叠加）

### 为什么用"死亡次数"而不是"战斗表现"

死亡次数是**最诚实、最难被玩家察觉的指标**。
而"命中率""弹开率"这类指标如果被玩家发现系统在监控，会引起不安。
死亡次数是本来就必然被记录的数据。

### DDA 与"三条通关路径"的关系

DDA 是**第四层保险**，在三条路径之下兜底：

```
路径 A（弹开一闪）  → 效率最高
路径 B（闪避普攻）  → 永远可行，只是慢
路径 C（资源鬼力）  → 需要探索投入
        ↓ 都还是过不去
DDA 悄悄放水        → 保证最终能过
```

## 4. 辅助选项（可及性设置）

独立于难度档的开关，全部可选，默认关闭（除标注外）：

### 4.1 战斗辅助

| 选项 | 效果 | 为什么不做成自动 |
|---|---|---|
| **半自动防御** | 按住防御时，若没手动弹开，系统在命中前 2 帧自动判定弹开（但**每 10 秒只能触发 3 次**） | 有次数限制，不会变成"无敌"。它只是把"精准时机"换成"资源管理" |

> ⚠️ **半自动防御只对「一般攻击」生效，对「危」攻击一律不生效**（2026-09-12 制作人补注）。
> 依据 02 §3 的裁定：**闪应对一切，弹开只应对一般攻击**。
> 如果让辅助去自动弹开危攻击，等于把"危必须换手段应对"这条设计整个抹掉——
> 辅助可以降低**操作门槛**，但不能取消**判断门槛**（05 §1 的立场）。
| **危攻击提示音分型** | 突刺=高音 / 横扫=中音 / 抓取=低音 | 这个**默认开启**，属于无障碍，不是降难度 |
| **弹开节拍提示** | 敌人攻击命中前 6 帧，屏幕边缘白色脉冲 + 弱拍音 | 类似音游的节拍轨，把视觉判断转成听觉判断 |
| **攻击预警圈** | 敌方攻击落点显示地面圈 | |
| **自动锁定目标** | 自动选最近敌人 | |
| **镜头震动强度** | 0~100% 滑条 | 晕动症玩家必需 |
| **慢镜时长** | 0（关闭）/ 标准 / 加长 | 一闪慢镜看多了会烦，也给想快点打的玩家 |

### 4.2 感官与操作

| 选项 | 说明 |
|---|---|
| **画面闪烁减弱** | 一闪的黑白闪、命中白闪全部降低强度或改为颜色变化 |
| **血/红色替换** | 把血色改为蓝色/绿色（部分玩家对血敏感） |
| **字幕** | 全部对话有字幕，且字号可调 |
| **键位重映射** | 全部按键可改，包括手柄 |
| **长按/连打切换** | 需要连打的 QTE 可改为长按 |
| **UI 缩放** | HUD 元素可放大到 150% |
| **体积单位可读性** | 体干条除了颜色，还有数值和形状变化（不依赖颜色区分） |

### 4.3 色盲与低视力

- **弹性/体干条不只靠颜色**：玩家条是"向上生长"，敌人条是"左右收缩"，
  形状不同，灰度下也能区分
- 敌人「危」攻击除了红色，还有一个**高对比度的图形符号**（三角/圆/方，
  对应突刺/横扫/抓取），灰度和色盲下都能读
- 所有关键 UI 元素对比度 ≥ 4.5:1

### 4.4 练习房（道场）

**这是本项目最重要的可及性功能。**

一个可随时进入的训练场，包含：

| 训练模块 | 内容 |
|---|---|
| 木桩 | 练连段、看帧数据、无限血 |
| 攻击模式固定的假人 | 只会一招「横斩」，循环释放 → 专练弹开 |
| 危·突刺假人 | 专练看破 |
| 危·横扫假人 | 专练避一闪 |
| 拼刀假人 | 专练拼刀输入窗 |
| 已击败 BOSS 的幻影 | 重打已通关的 BOSS，**死后 1 秒立刻重开** |

道场里可以开启**慢放**和**显示判定窗**（正式战斗里不能开，避免依赖）。

> 道场的作用：把"我在战斗里被虐"变成"我在道场里练习"。
> 这是让手残玩家留下来的关键——**给了他们一个安全的、不丢脸的进步空间**。

## 5. 教学关设计（渐进式）

教学不是一段教程文字，是**一个个独立可死的场景**。

| 阶段 | 教什么 | 怎么教 |
|---|---|---|
| 序章 | 移动 / 视角 / 锁定 | 走路、开门、看风景，无敌人 |
| 序章 | 攻击 / 三连击 | 打不会还手的木桩 |
| 序章 | 格挡 | 一个只会慢慢砍的假人，只教"按住防御不掉血" |
| 序章 | 闪避 | 一个只会砸地的假人，教无敌帧 |
| 第一章 | **弹开** | 师父幻影："在刀落下的瞬间按下防御" → 3 次成功即过关 |
| 第一章 | 看破（危·突刺） | 只有突刺的枪兵，反复练 |
| 第二章 | **一闪** | 师父幻影演示 → 玩家对着"慢速假人"试 → 成功 2 次过关 |
| 第二章 | 拼刀 | 设计一场"必拼刀"的演出战 |
| 第三章 | 蓄力斩 / 鬼力 | 需要破防的石头敌人 + 需要远程的元素敌人 |

**教学铁律**：
1. 每教一个机制，**只教这一个**，不同时教第二个
2. 教学场景**允许死亡**，但死后 2 秒内原地重开，无惩罚
3. 教学提示**只在失败 2 次后出现**（不打断第一次尝试的沉浸感）
4. 所有教学提示可在设置里关闭（给老玩家快速通过）

## 6. 防劝退检查清单（每次内容更新后过一遍）

这份清单是验收标准，任何一条不成立就要改：

### 死亡与失败
- [ ] 死亡惩罚：魂可原地取回？**是**
- [ ] 死亡到重开的等待时间 ≤ 3 秒？**是**（不做长死亡动画）
- [ ] BOSS 战有中途存档点（BOSS 前 20 秒路程）？**是**
- [ ] 死亡界面没有嘲讽性文案？**是**（不写"你死了"，写"再试一次"）

### 学习曲线
- [ ] 每个新机制都有专属的无惩罚练习场景？**是**
- [ ] 每个 BOSS 只考 1~2 个机制，不叠加？**是**
- [ ] 玩家失败时，能否明确知道"我哪里做错了"？**必须能**（攻击可读性）
- [ ] 同一个 BOSS 第 3 次挑战时，是否明显比第 1 次好？**必须**

### 操作宽容
- [ ] 所有"时机判定"都有容错帧？**是**（见 02 文档 §8）
- [ ] 按错键的最坏后果是"没效果"而不是"被打死"？**是**（一闪安全窗）
- [ ] 输入缓冲覆盖所有动作？**是**
- [ ] 是否存在"知道怎么做但手做不到"的设计？**必须为 0**

### 路径可行性
- [ ] 完全不弹开，只用闪避+普攻能打过每个 BOSS？**必须能**
- [ ] 完全不用一闪能打过每个 BOSS？**必须能**
- [ ] 只用鬼力（远程）能磨过每个 BOSS？**至少大部分能**
      —— ⚠️ **这条从 1.0（= M5 垂直切片）的验收里移除**，见下方分档说明

> **验收分档（2026-09-12 制作人修订）**
>
> | 档位 | 需要保证的路径 |
> |---|---|
> | M5 = 1.0 发布版 | **路径 A（技巧）+ 路径 B（基础）** |
> | 1.0 之后（原 M7 内容） | 路径 C（资源流） |
>
> 路径 C 的验证需要鬼力三元素、升级三线、消耗道具全部到位，
> 那是内容层的工作量。把它放进 1.0 的验收标准，等于用一个做不完的门槛挡住一个做得完的产品。

### 心理感受
- [ ] 有没有任何文案/UI 暗示玩家"技术差"？**必须为 0**
- [ ] 输了之后有没有"再来一次"的冲动？**这是最终检验**
- [ ] 通关后是否想"再打一遍打好看点"？**这是 1.0 的成功标准**

## 7. 难度曲线（按关卡）

```
难度
 ↑
 │                                          ╱ 终章 BOSS
 │                                    ╱────╱   (3 阶段)
 │                          ╱────╱ 第五章
 │                    ╱────╱  四章(机制综合)
 │              ╱────╱  三章(新机制密集)
 │        ╱────╱  二章(一闪)
 │  ────╱  一章(弹开)
 │ ╱ 序章(教学)
 └──────────────────────────────────────────→ 时间
   ↑         ↑          ↑         ↑
 零压力   有失败可能   需要技巧   需要掌握
```

关键点：**在第四章放一个"回落"**。
第四章（魔空空间）是资源压力关，战斗密度降低，让玩家喘口气，
同时把已有的所有机制再练一遍。直接一路上升会让人疲劳。

BOSS 难度节奏：
1. 鬼哭（一章）— 教弹开，**允许靠格挡+闪避硬过**
2. 焰（二章）— 教一闪，**必须至少用出 1 次一闪才比较轻松**
3. 咒（三章）— 教鬼力和多目标处理
4. 影（四章）— 综合考验，会用玩家的一闪（镜像战）
5. 刃 + 骸（五章）— 双 BOSS，连锁一闪的主场
6. 第六天魔王（终章）— 3 阶段，全部机制

每个 BOSS 的**第 2 阶段难度不能断崖**。常见错误是 P1 很轻松、P2 直接劝退。
我们要求：P2 的新增压力 ≤ P1 的 1.4 倍，且 P2 开场的第一个攻击必须是**玩家已经会的机制**。
