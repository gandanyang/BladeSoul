#### 1.1.1 动作不是清单，是矩阵（2026-09-15 升级）

上面那张表是"我们有哪些动作"；但它回答不了"**同一个动作能不能有多种含意**"。
参照成熟动作系统的拆法（`ONIMUSHA-DEMO-REF.md` §四），把动作放进三个**正交轴**：

| 轴 | 取值 | 谁决定 |
|---|---|---|
| **触发来源** | 直接输入 / 弹开后 / 闪避后 / 拼刀胜后 / 破防后 / 连锁 | 玩家输入 + 状态机 |
| **攻击性质** `DamageType` | `Slash` / `Thrust` / `Blunt` / `Dark`（**已在 `CombatEnums.cs`**） | 攻击数据 `.tres` |
| **结果状态** | 收招 / 连段 / 可处决 / 窗口重计时 / 硬直 | 状态机 |

★ **关键点：不增加玩家输入，只增加同一动作的"语义出口"。**
`IssenKind` 里**现在就躺着** `Shin / Deflect / Dodge / Clash / Chain` 五种——
其中 `Dodge`/`Clash` 两个出口按生产裁定**暂缓接线**（见 `ONIMUSHA-DEMO-REF.md` §4.2）。

> ⚠️ **持刀姿态（片手/両手）不列为轴**：生产已裁定**固定单一持刀姿态**
> （偏单手、轻盈、近距离、精准）。这是**范围决策**，不是美术决策——双持会让动作数 ×2，
> 而程序化动画下真正的瓶颈是维护成本。

#### 1.1.3 反馈档（强度）× 攻击性质（质感）——**两个不同的东西**

**别把"强度"和"质感"混成一个档位。** 它们是两层：

- **强度档 F1~F5**：决定 `VFX 数量 / SFX 音量 / 震动幅度 / 顿帧长度` 的**量级**。
- **攻击性质 `DamageType`**：在**同一强度档内**决定**音色 / 火花形状 / 震动曲线**。

| 档 | 名称 | 典型事件 |
|---|---|---|
| F1 | 轻微 | 闪避 / 格挡抬起 / 轻受击 |
| F2 | 中等 | 轻斩命中 / 突刺命中 |
| F3 | 重 | 重击（蓄力） / 体干破裂 |
| F4 | 一闪级 | 一闪 / **弹开成功** |
| F5 | 处决级 | 处决命中 |

**弹开（F4 基准）的四种质感**（这是 T53 的内容，**纯数据驱动**）：

| `DamageType` | 音色 | 火花 | 震动 |
|---|---|---|---|
| `Slash` | 清脆金属撞击 | 横向长条火花 | 中 |
| `Blunt` | 沉闷冲击 | 少而散的碎屑 | **重、带拖尾** |
| `Thrust` | 尖锐短促 | 短促集中 | 短促尖峰 |
| `Dark` | 低频闷响 | 暗色粒子 | 低 |

**实现形态（建议）**：`Deflect(AttackType)` → 查一份 `DeflectFeedbackProfile`
（`VFX / SFX / CameraShake / HitStop / Pitch`）→ 各通道取值。
**具体数值不写死在代码里**，进 `data/**/*.tres`（沿用项目"一个数字一个来源"的纪律）。

## 6. 音频总线布局

在 Godot 的 Audio 面板建以下总线：

```
Master
├─ Music        (BGM)
├─ SFX          (战斗音效)
│  ├─ Combat    (命中/弹开/拼刀 —— 需要突出)
│  └─ Ambience  (环境音)
├─ Voice        (角色语音)
└─ UI           (菜单音效，不受慢镜影响)
```

**重要**：`Engine.TimeScale` 会改变音频播放速度。
一闪慢镜时，如果走 `Master` 总线，音乐会变调。

对策：慢镜用逐 actor 顿帧为主（不影响音频），
必须用 `TimeScale` 的场合，给 `Music` 总线单独处理
（或干脆接受慢镜时音乐轻微变调，反而有风格）。

## 7. 渲染与性能预算

> **掉帧时的降级顺序（2026-09-12 制作人裁定，不许自己改顺序）：**
>
> **① 砍体积雾 → ② 砍粒子数量 → ③ 砍同屏敌人数 → ④ 最后才允许掉到 30fps。**
>
> 理由与 01 文档的北极星一致：**手感（帧率与顿帧的准确性）优先于画面。**
> 一个掉到 40fps 的弹开，判定窗会变得不可信——那等于把核心机制弄坏了。
> 下面这张表是目标值，不是承诺值；冲突时按上面的顺序让步。

| 项 | 目标 |
|---|---|
| 分辨率 | 1920×1080 |
| 帧率 | 60 fps（物理 60Hz，开启物理插值） |
| 同屏敌人 | ≤ 8 |
| 单帧 Draw Call | ≤ 800 |
| 三角面（同屏） | ≤ 150 万 |
| 材质 | 优先 `StandardMaterial3D`，慎用大量自定义 shader |

### 视觉风格设定

| 项 | 设定 |
|---|---|
| 渲染后端 | Forward+ |
| 色调 | 暗黑战国：低饱和 + 血红/紫黑魔气 |
| 时间 | 多为黄昏/雨夜（减少光照复杂度，也符合氛围） |
| 抗锯齿 | TAA（Godot 4 默认） |
| 后处理 | 轻微辉光（Bloom）+ 暗角（Vignette）+ 色调映射 |
| 雾 | 体积雾（营造氛围，也能遮掩远处的低模） |

> 选"雨夜 + 体积雾"不只是氛围考虑，也是**省美术的实用选择**：
> 雾能遮住远景，雨能统一色调，暗环境能降低贴图精度要求。

## 8. 资产引入纪律

1. **每个资产先问**：它是 P0（M5 需要）还是可以往后放？
   M5 之前只引 P0，避免过早陷入资产整理
2. **命名规范**：`类别_名称_变体.扩展名`
   - `anim_player_attack_light_01.glb`
   - `sfx_deflect_01.ogg`
   - `vfx_hit_blood_01.tscn`
3. **目录规范**：`assets/anim/` `assets/audio/` `assets/models/` `assets/vfx/` `assets/ui/`
4. **立即记 CREDITS**：引入时当场记，不要"以后再补"
5. **导入设置统一**：动画 FPS = 60；音频走对应总线；贴图按需压缩
