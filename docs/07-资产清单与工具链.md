## 2. 音效需求清单

**音效是战斗手感的 50%，M2 就必须接上占位音频。**
免费来源见 §4。

### 2.1 战斗核心（P0，M2 必须）

| 音效 | 说明 | 变体数 |
|---|---|---|
| `hit_slash` | 切割肉身 | 3 |
| `hit_block` | 被格挡（钝响） | 2 |
| `deflect` | **弹开（金属尖鸣，音高可调）** | **1（音高程序化调整）** |
| `clash` | 拼刀（低频锵） | 2 |
| `guard_break` | 体干破裂（骨裂） | 2 |
| `issen_slash` | 一闪切割 | 2 |
| `issen_impact` | 一闪低频轰鸣 | 1 |
| `deathblow` | 忍杀 | 1 |
| `whoosh_light` / `whoosh_heavy` | 挥空 | 2+2 |
| `dodge_whoosh` | 闪避风声 | 1 |

**弹开的音高递增是程序化实现**：不准备 12 个音频文件，
用 `AudioStreamPlayer.PitchScale` 每次 +2 半音（× 1.122）。

### 2.2 危攻击预警（P0，可及性必需）

三个不同音高，让玩家闭眼能分辨：

| 音效 | 对应 | 相对音高 |
|---|---|---|
| `perilous_thrust` | 危·突刺（可看破） | 高（+7 半音） |
| `perilous_sweep` | 危·横扫（需闪避） | 中（0） |
| `perilous_grab` | 危·抓取（只能闪） | 低（−7 半音） |

不要用同一个音效改音量 —— 音高才是可分辨的维度。

## 6. 音频总线布局

在 Godot 的 Audio 面板建以下总线：

```
Master
├─ Music        (BGM)
├─ SFX          (战斗音效)
│  ├─ Combat    (命中/弹开/拼刀 —— 需要突出)
│  └─ Ambience  (环境音)
├─ Voice        (角色语音)
└─ UI           (菜单音效，不受慢镜影响)
```

**重要**：`Engine.TimeScale` 会改变音频播放速度。
一闪慢镜时，如果走 `Master` 总线，音乐会变调。

对策：慢镜用逐 actor 顿帧为主（不影响音频），
必须用 `TimeScale` 的场合，给 `Music` 总线单独处理
（或干脆接受慢镜时音乐轻微变调，反而有风格）。

## 7. 渲染与性能预算

| 项 | 目标 |
|---|---|
| 分辨率 | 1920×1080 |
| 帧率 | 60 fps（物理 60Hz，开启物理插值） |
| 同屏敌人 | ≤ 8 |
| 单帧 Draw Call | ≤ 800 |
| 三角面（同屏） | ≤ 150 万 |
| 材质 | 优先 `StandardMaterial3D`，慎用大量自定义 shader |

### 视觉风格设定

| 项 | 设定 |
|---|---|
| 渲染后端 | Forward+ |
| 色调 | 暗黑战国：低饱和 + 血红/紫黑魔气 |
| 时间 | 多为黄昏/雨夜（减少光照复杂度，也符合氛围） |
| 抗锯齿 | TAA（Godot 4 默认） |
| 后处理 | 轻微辉光（Bloom）+ 暗角（Vignette）+ 色调映射 |
| 雾 | 体积雾（营造氛围，也能遮掩远处的低模） |

> 选"雨夜 + 体积雾"不只是氛围考虑，也是**省美术的实用选择**：
> 雾能遮住远景，雨能统一色调，暗环境能降低贴图精度要求。

## 8. 资产引入纪律

1. **每个资产先问**：它是 P0（M5 需要）还是可以往后放？
   M5 之前只引 P0，避免过早陷入资产整理
2. **命名规范**：`类别_名称_变体.扩展名`
   - `anim_player_attack_light_01.glb`
   - `sfx_deflect_01.ogg`
   - `vfx_hit_blood_01.tscn`
3. **目录规范**：`assets/anim/` `assets/audio/` `assets/models/` `assets/vfx/` `assets/ui/`
4. **立即记 CREDITS**：引入时当场记，不要"以后再补"
5. **导入设置统一**：动画 FPS = 60；音频走对应总线；贴图按需压缩
