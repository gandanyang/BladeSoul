# 03 · 剧情与关卡流程

> 参考对象：《鬼武者》系列（含 2026-09-04 发售的《鬼武者 剑之道》）的**剧情结构公式**，
> 不是照搬它的剧情内容。文末有 IP 风险的原创化替换建议。

### 不依赖新作细节的理由

**规划不该依赖一款刚发售一周的游戏的剧情细节。** 我们参考的是
《鬼武者》系列沿用 20 多年的**结构公式**，这部分资料充分且稳定：

> 幻魔袭击 → 主角获得鬼之笼手 → 杀敌吸魂变强 → 层层揭开魔王阴谋 →
> 打倒四天王 → 直面第六天魔王 → 封印/净化

这套公式在《鬼武者 1/2/3/新鬼武者》中反复使用，是可靠的参考模板。

## 1. 鬼武者式剧情结构公式（我们的骨架）

| 节拍 | 内容 | 在我们的项目里 |
|---|---|---|
| **1. 灾变** | 主角所在之地被幻魔袭击，卷入事件 | 序章：稻叶山城落城 |
| **2. 获得力量** | 得到鬼之笼手，能与幻魔之魂共鸣 | 序章末：师父战死，托付笼手 |
| **3. 成长循环** | 杀幻魔 → 吸魂 → 强化武器/解锁元素 | 全程：魂系统 + 鬼力三元素 |
| **4. 揭开幕后** | 逐步发现魔王的阴谋，敌方干部登场 | 第一~四章：四天王陆续出现 |
| **5. 干部战** | 依次击破四天王 | 第二~五章 |
| **6. 最终决战** | 直面第六天魔王，多阶段 | 终章：织田信长三阶段 |
| **7. 结局** | 封印/净化，多结局分支 | 净化 / 献祭 / 隐藏 |

**关键**：这套公式天然适配"关卡制动作游戏"，而且天然适配我们的教学节奏——
每个干部（BOSS）恰好可以教一个战斗机制。

## 2. 我们的世界观

**时代**：战国末期，天正年间（历史架空）
**舞台**：京都及其周边（本作参考作的舞台），加上架空的"魔空空间"

**内核**：
> 第六天魔王·织田信长 与异界之魔「**魔骸**」缔结血契，以人间气血换取不死之身。
> 血契的代价是：被他征服的土地上，死者会化为魔骸复苏。
> 唯一的对抗手段，是已经灭亡的「**鬼之一族**」留下的遗物——**噬魂笼手**，
> 它能夺取魔骸的魂魄，转化为持有者的力量。

**主角**：无名的流浪剑客（玩家可命名，默认「**丛云**」）
**师父**：鬼之一族末裔「**玄斎**」，序章战死，托付笼手（也是教学关的引导者幻影）
**反派**：织田信长（第六天魔王）+ 四天王（火/咒/刃/骸）

> 主角刻意设定为**无名浪人**而不是历史名人：
> 1. 玩家更容易代入
> 2. 避免与宫本武藏、明智左马介等既有形象产生直接比较
> 3. 留出创作自由度

## 3. 术语对照与原创化替换建议（IP 安全）

⚠️ **重要**：以下是 Capcom 的专有名词。个人学习/练习项目不受限，
但**如果要公开发布（哪怕免费），必须替换。**

| 参考术语 | 归属 | 我们的替换建议 |
|---|---|---|
| 幻魔 (Genma) | Capcom 专有 | **魔骸**（Makugai） |
| 鬼之笼手 (Oni Gauntlet) | Capcom 专有 | **噬魂笼手**（Shikikon no Kote） |
| 鬼武者 (Onimusha) | Capcom 专有 | 项目名 **鬼刃 / ONIBLADE** |
| 魂（红/黄/蓝） | 通用概念，但配色是其特征 | **魄**（赤魄/黄魄/青魄） |
| 织田信长 / 第六天魔王 | **历史人物 + 历史称号，可用** | 保留（历史公有领域） |
| 稻叶山城 / 岐阜 / 安土 / 本愿寺 | **历史地名，可用** | 保留 |
| 一闪 (Issen) | **通用日语剑术术语，可用** | 保留 |
| 拼刀 / 弹开 / 看破 | 通用动作游戏术语 | 保留 |

**结论**：
- 历史人名、地名、称号（信长、第六天魔王、稻叶山城、本能寺）**安全**，属于公有领域
- 虚构设定名词（幻魔、鬼之笼手）**必须替换**
- 战斗术语（一闪、弹开、拼刀）**安全**

## 4. 章节流程

先明确**三档交付范围**，避免各文档口径打架：

| 范围 | 包含章节 | 时长 | 对应里程碑 |
|---|---|---|---|
| **MVP / DEMO** | 序章 + 第一章 | 15~20 分钟 | M5 |
| **1.0 发布版** | 序章 + 第一~三章 + 终章（简化） | **3.5~4 小时** | M7 |
| **完整愿景**（1.0 之后） | 全部 7 章 | 约 6.5 小时 | 后续 |

下面按完整愿景列出 7 章，**第四、五章标记为「1.0 之后」**。

### 序章 · 落城（20 分钟，纯教学）

| 项 | 内容 |
|---|---|
| 场景 | 雨夜 · 稻叶山城 天守 |
| 剧情 | 城池陷落，魔骸涌入。师父玄斎为掩护主角战死，临终将噬魂笼手托付给主角 |
| 玩法 | 移动 / 视角 / 锁定 / 攻击三连 / 格挡 / 闪避 |
| 敌人 | 无（或 1 个不会还手的魔骸残兵） |
| BOSS | 无 |
| 教学载体 | 师父的"残魂幻影"在后续章节中以幻影形式继续指导（低成本，无需全程配音） |
| 情绪目标 | 无力感 → 获得力量 → 想复仇 |

**设计要点**：序章**不能有失败可能**。玩家在这里只该体验"我很帅"。

---

### 第一章 · 岐阜城下（60 分钟）

| 项 | 内容 |
|---|---|
| 场景 | 被魔骸占据的城下町、废弃神社、地下水道 |
| 剧情 | 主角追查师父遗言中的线索，发现信长与魔骸的血契。救下幸存者，得知四天王的存在 |
| 教学 | **弹开**（核心）→ **看破**（危·突刺） |
| 敌人 | 魔骸足轻（刀）、魔骸枪兵（~~魔骸弓兵~~：1.0 之后） |
| 精英 | 魔骸足轻队长 ×3 |
| **BOSS** | **「鬼哭」** — 双刀魔骸武士 |
| 情绪目标 | 第一次真正的胜利——"我能打赢他们" |

**BOSS「鬼哭」设计**（教弹开）
- P1（100%~50%）：横斩、二连斩 → 纯粹练弹开
- P2（50%~0%）：加入危·突刺、拼刀往返演出
- **必须能靠"格挡+闪避+普攻"硬过**（验证路径 B）
- 弱点是弹开后的弹一闪窗口

---

### 第二章 · 安土城（75 分钟）

| 项 | 内容 |
|---|---|
| 场景 | 信长居城的外廓、火器工坊、燃烧的庭院 |
| 剧情 | 四天王之一「焰」镇守。主角得知血契需要献祭，京都将成为祭坛 |
| 教学 | **一闪**（真一闪 / 弹一闪）、**拼刀** |
| 敌人 | 新增魔骸火卒（火属性，需用雷系鬼力克制） |
| 精英 | 魔骸武士 ×2 |
| **BOSS** | **四天王·「焰」** — 巨型火属性魔骸 |
| 情绪目标 | "我不只是能挡，我还能一击必杀" |

**BOSS「焰」设计**（教一闪）
- 巨汉体型，攻击**不可弹开**（危·横扫、重砸）→ 强制玩家学闪避 + 避一闪
- 大范围火焰攻击 → 教走位
- 火焰护体时只能靠一闪破防 → **一闪从"可选"变成"必需"**
- 但仍保留路径 B：护体可被蓄力斩慢慢破（时间长 3 倍）

---

### 第三章 · 比叡山（75 分钟）

| 项 | 内容 |
|---|---|
| 场景 | 破戒僧盘踞的山寺、雪道、悬空回廊 |
| 剧情 | 四天王「咒」以妖术操控僧众。主角获得第二、第三种鬼力元素 |
| 教学 | **蓄力斩**、**鬼力三元素**、**多目标处理** |
| 敌人 | 魔骸僧兵、术士（远程压制）（**1.0 之后**） |
| 精英 | 妖术僧 ×2 |
| **BOSS** | **四天王·「咒」** — 妖术师 |
| 情绪目标 | "我有了更多手段" |

**BOSS「咒」设计**（教资源管理）
- 本体脆弱但召唤小怪 + 远程术弹
- 教"优先击杀威胁目标"
- 术弹可被刀斩落 → 教主动应对远程
- 弱点：雷系鬼力

---

### 第四章 · 魔空空间（60 分钟，节奏回落）— **1.0 之后**

| 项 | 内容 |
|---|---|
| 场景 | 异界回廊，非线性的"魂之回廊" |
| 剧情 | 主角被拖入魔空空间，直面自己的影子——「影」 |
| 教学 | 无新机制，**综合复习** |
| 玩法 | 资源压力关：魂多、敌人强、无存档点（一段路） |
| **BOSS** | **「影」** — 主角的镜像 |
| 情绪目标 | "我变强了"的自我确认 |

**BOSS「影」设计**（综合考验）
- 会使用玩家会的所有招式，**包括一闪**
- 玩家必须用"安全窗"逻辑应对——它也会一闪你
- 打赢它 = 玩家真正掌握了自己

> **节奏设计**：这一章战斗密度降低，是刻意的"回落"。
> 连续 4 章上升会让玩家疲劳（见 05 文档 §7）。

---

### 第五章 · 本能寺（75 分钟）— **1.0 之后**

| 项 | 内容 |
|---|---|
| 场景 | 燃烧的本能寺、无存档长段 |
| 剧情 | 四天王「刃」与「骸」合流。师父的死因揭开 |
| 教学 | 无新机制，**双 BOSS 处理** |
| 玩法 | 连续精英战 + 长段无存档（给硬核玩家的挑战） |
| **BOSS** | **四天王·「刃」+「骸」** — 双打 |
| 情绪目标 | "我已经能同时应对两个强敌" |

**BOSS「刃」+「骸」设计**（连锁一闪主场）
- 双目标，考验锁切换与走位
- 连锁一闪在这里收益最大（一次连割两人）
- Gank 规则：最多 2 人同时进攻（见 02 文档）

---

### 终章 · 第六天魔王（45 分钟）

| 项 | 内容 |
|---|---|
| 场景 | 安土城天守最上层 → 魔化空间 |
| 剧情 | 直面织田信长，揭穿血契真相 |
| **BOSS** | **织田信长（三阶段）** |
| 情绪目标 | 复仇 → 抉择 |

**织田信长三阶段**

| 阶段 | 形态 | 考验 | 新增机制 |
|---|---|---|---|
| P1 | 人形剑术 | 弹开 + 拼刀 | 与人类剑客的对决，节奏快 |
| P2 | 魔骸化 | 危攻击密集 + 一闪时机 | 攻击速度提升，窗口收窄 |
| P3 | 天魔形态 | 鬼力 + 全机制综合 | 巨大化，弱点随阶段移动 |

**阶段过渡不能断崖**（05 文档 §7 的硬要求）：
P2 开场的第一个攻击必须是**玩家已经会的机制**（比如一个横斩），再做难度爬升。

## 5. BOSS 设计总结表

| 章 | BOSS | 教的机制 | 阶段数 | 允许"硬磨"过关？ | 在 1.0 内？ |
|---|---|---|---|---|---|
| 一 | 鬼哭 | 弹开 | 2 | ✅ 可以（路径 B） | ✅ |
| 二 | 焰 | 一闪、闪避 | 2 | ✅ 可以（慢 3 倍） | ✅ |
| 三 | 咒 | 鬼力、多目标 | 2 | ✅ 可以 | ✅ |
| 终 | 织田信长 | 全部（1.0 版为 2 阶段） | 2~3 | ✅ 可以（DDA 兜底） | ✅ |
| 四 | 影 | 综合 | 2 | ⚠️ 较难，但可行 | ❌ 后续 |
| 五 | 刃 + 骸 | 双目标、连锁一闪 | 1（双人） | ⚠️ 较难 | ❌ 后续 |

**铁律**：任何一个 BOSS 都不允许做成"不弹开就绝对过不去"。
如果测试发现某 BOSS 卡住了"基础流"玩家，那就是设计失误，要改。

## 6. 魂 / 笼手 / 鬼力系统

### 6.1 三种魄（参考鬼武者的魂配色，但换了名字）

| 名称 | 颜色 | 作用 | 吸收方式 |
|---|---|---|---|
| **赤魄** | 红 | 经验值 → 升级 | 击杀后飘出，靠近自动吸附 |
| **黄魄** | 黄 | 立即回复体力 | 同上，血量低时自动优先吸 |
| **青魄** | 蓝 | 鬼力槽 | 同上 |
| **白魄** | 白（稀有） | 强化武器 / 解锁一闪变体 | 精英与 BOSS 掉落 |

**主动吸魂**：长按交互键可大范围吸取周围所有魄，
但期间**无法移动和防御**（有风险）。这是"贪心"的设计空间。

### 6.2 升级三条线（简化，不做复杂技能树）

| 线 | 提升 | 上限 |
|---|---|---|
| **体** | 最大体力、体干上限、体干恢复 | 10 级 |
| **技** | 攻击力、弹开窗 +1 帧（关键！）、一闪窗 +1 帧 | 10 级 |
| **魂** | 鬼力上限、鬼力回复、魄吸收范围 | 10 级 |

> **「技」线可以提升弹开窗**——这是给手残玩家的正道升级路径：
> 打不过就去刷魂，把弹开窗从 9 帧练到 11 帧。
> 数值成长直接转化为操作宽容度，而不是单纯的伤害数字。
> 这是"变强"这件事最可感知的形式（对应 01 文档的北极星）。

### 6.3 鬼力三元素

| 元素 | 效果 | 克制 |
|---|---|---|
| **焰** | 范围爆发，高体干伤 | 冰/木属性敌人 |
| **雷** | 单体高伤 + 麻痹 | 火属性（如 BOSS「焰」） |
| **风** | 位移 + 多段 | 群体、远程敌人 |

每种消耗鬼力槽。鬼力靠青魄和道具补充。

## 7. 关卡设计原则

| 原则 | 说明 |
|---|---|
| **遭遇战节奏** | 探索 2 分钟 → 战斗 30 秒 → 探索 2 分钟，不要连续战斗超过 2 波 |
| **Gank 上限** | 同屏最多 2 个敌人同时进攻，其余保持游走（见 02 文档 §10） |
| **存档点密度** | 每 3~5 分钟一个"鬼火"存档点；BOSS 前 20 秒必有一个 |
| **可见性** | 战斗区域必须有足够的空间（不能贴墙打），且背景不能干扰读招 |
| **可逃课** | 大部分精英战允许"绕过"或"地形杀"，不强推硬打 |
| **回头路** | 关卡有短回路，方便刷魂和取回掉落 |
| **单一机制** | 每个战斗区域只考 1~2 个机制，不叠加 |

### 关卡布局模板

```
[入口] → 探索段(拾取/剧情) → 遭遇战A(2杂兵) → 探索段 → 
遭遇战B(3杂兵+1精英) → 鬼火存档 → 短探索 → [BOSS房]
```

## 8. 三档范围的裁剪线（重点）

### 档位 1：M5 垂直切片 = 可发布的 DEMO（15~20 分钟）

| 内容 | 范围 |
|---|---|
| 剧情 | 序章 + 第一章（完整） |
| 关卡 | 岐阜城下（约 10 分钟流程） |
| 战斗系统 | 格挡/弹开/拼刀/一闪家族/体干/忍杀 —— **全部做完** |
| 敌人 | 魔骸足轻（刀）、魔骸枪兵（危·突刺）2 种 |
| 精英 | 1 个（魔骸足轻队长） |
| BOSS | 1 个（鬼哭，2 阶段） |
| 系统 | 魂 / 升级（仅「技」线）/ 存档 / 死亡复活 |
| 教学 | 序章的渐进教学 + 弹开教学 |

**这就是一个完整、可发布、值得给人玩的 DEMO。**
把它免费发出去收反馈，比闷头做半年更有价值。

### 档位 2：M7 = 1.0 发布版（**3.5~4 小时**）

在档位 1 基础上加：

| 内容 | 范围 |
|---|---|
| 剧情 | 加上第二章、第三章、终章（简化版） |

## 9. 结局分支

## 10. 叙事呈现方式（低成本方案）

**不做**全程配音和过场动画。用以下方式：

| 方式 | 用途 | 成本 |
|---|---|---|
| **黑屏字卡** | 章节标题、时间地点 | 极低 |
| **图文对话框** | 主要剧情对话（半身立绘 + 文字） | 低 |
| **场景演出** | 关键节点用游戏内动画（如师父战死用引擎演） | 中 |
| **师父残魂** | 教学提示伪装成"师父在说话" | 低 |
| **环境叙事** | 尸体、血字、残破的家书 | 低（但效果好） |
| **BOSS 登场演出** | 每个 BOSS 一个 5 秒的登场镜头 | 中，但值得 |

> 其中**环境叙事**性价比最高：一封家书、一具母亲护着孩子的尸体，
> 比 10 分钟对话更能建立"魔骸很残忍"的印象，且几乎零成本。

**音效上的叙事**：每次吸收赤魄时笼手发出低鸣，
随着剧情推进（主角被笼手侵蚀）音效逐渐变得不安——
一个不需要任何台词的、贯穿全程的叙事线索。
