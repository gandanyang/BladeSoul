# 09 · 主角「丛云」外观设定（建模用）

> 本文只讲**长什么样**。人设与剧情见 [03-剧情与关卡流程](03-剧情与关卡流程.md) §2.5。
> 目标读者：建模 / 绑定 / 材质。

---

## 1. 一句话造型主题

> **他身上每一件东西都是别人给的、捡来的、改过的——只有那只手不是他的。**

这句话决定所有取舍：

- 衣服**不成套**（他没有家，没有人为他置办一身）
- 刀**朴素、实用**（那是自己练出来的东西）
- **笼手是全场唯一一件"完整、精密、不属于人间"的物件**

造型上的一切对比都服务于这一句：**旧的、软的、灰的（人）** × **新的、硬的、紫黑的（笼手）**。

---

## 2. 剪影（第一优先级，比细节重要）

本作是 TPS 越肩视角，**玩家 90% 的时间在看他的背面**。
剪影必须回答三个问题：**朝哪边 / 在做什么 / 现在是什么状态。**

| 要求 | 做法 |
|---|---|
| 一眼看出朝向 | 右肩明显高于左肩（右手持刀的自然体态）；左臂略内收 |
| 一眼看出体型 | **偏瘦、筋瘦，不是健美**。肩窄、腰细、四肢结实但不粗 |
| 一眼认出是浪人 | **无兜、无家纹、无肩甲**。头部轮廓干净，靠参差的头发与衣领破口做辨识 |
| 背面要有动态 | 背后斜挎一条旧布带，挂**酒壶与布袋**（他全部的家当）。跑动时飘动，是背面唯一的活跃元素 |
| 一眼看出状态 | 笼手的**自发光强度**是唯一的状态指示灯（见 §6） |

**身体比例**：身高 ≈ 175cm，头身比 ≈ 7.2。
**不要做成 8 头身的英雄比例**——他不是一个"看起来很能打"的人，是一个**看起来吃过苦的人**。

---

## 3. 配色板

整体低饱和（07 §7：暗黑战国、低饱和 + 血红/紫黑魔气、多为黄昏/雨夜）。
在雾和暗环境里**靠明度差与高光辨识，不靠贴图细节**。

| 部位 | 颜色 | Hex |
|---|---|---|
| 皮肤 | 低饱和黄褐（略脏） | `#B99A80` |
| 头发 | 近黑 | `#1B1A1C` |
| 上衣（小袖/襦袢） | 褪色蓝灰 | `#4A5560` |
| 袴 | 土褐 | `#3E372F` |
| 绑腿 / 护腕 | 旧皮革 | `#4A3E32` |
| 腰带 / 绑带 | 亚麻原色（脏） | `#8A7A4E` |
| 刀鞘 | 暗褐漆（磨损） | `#2E2620` |
| 刀身刀背 | 冷钢 | `#A8B0BB` |
| 刀身刃口 | 亮钢 | `#D8DEE6` |
| **笼手底** | 黑紫 | `#241C2E` |
| **笼手纹路** | 紫 + 自发光 | `#6B3E8C` / `#A855F7` |

### ⚠️ 配色纪律：**主角身上不许出现红色**

红色与紫黑是**魔骸与血**的专属色（07 §7）。
当前灰盒里主角的强调色是暗红（`0.55, 0.16, 0.14`）——**这会和敌人撞色，必须改**。

> **规则：暖色饱和的地方 = 敌人。**
> 主角身上只有低饱和的旧色 + 笼手的紫。玩家唯一一次在自己身上看到紫黑，就是笼手。

## 4. 逐部件

### 4.1 头部

- 头发：**自己剪的**，长度不齐、后颈有一撮没剪到。用一根旧布条随便束住。
- 脸：年轻（20 上下），**眼下有疲态**。
- **不要疤、不要异色瞳**——他的"非人感"全部交给笼手。
- 默认表情：**中性偏紧**（不是凶，是"不太会放松"）。
- ⚠️ **不要面具、不要斗笠、不要头巾**——那是"酷"的符号，他不是那种人。

### 4.2 上身（三层，别更多）

1. **襦袢 / 小袖**（内层，`#4A5560`）：袖口短一截，露出小臂——为了露出笼手。
2. **简易胴**（中层，旧皮革板 + 布）：只有胸腹一小块，**没有肩甲**。看得出来是自己拿皮子钉的。
3. **外披破布 / 短蓑**（`#3A352C`）：挡雨，下摆破。跑动时飘。

补充细节：**左臂袖子明显比右边旧**（常年用右手，左手少动）。便宜，但有效。

### 4.3 下身

- 袴（`#3E372F`），**束脚**（踏鞴袴）——因为要跑、要跳。
- 草鞋 + 绑腿。**不做护胫**（他买不起）。

### 4.4 武器

| 项 | 设定 |
|---|---|
| 类型 | 打刀（略短于太刀），**实用、无铭** |
| 尺寸 | 刃 ≈ 70cm / 柄 ≈ 25cm（**不是夸张的大刀**） |
| 刀镡 | 素铁圆镡，无纹 |
| 刀鞘 | 磨损暗褐漆，**鞘尾有一圈后来补上的铜箍**（师父修的） |
| 佩挂 | 腰左，**鞘会随动作摆动**（绑定要点） |

**不要做成名刀。** 他所有的东西都不贵，贵的是他练剑的时间。

### 4.5 背后

- 一条旧布带斜挎，挂：**陶酒壶**（缺了一角）+ **干粮布袋**。
- 这是他全部家当，也是背面剪影里唯一的活跃形状。

---

## 5. ★ 噬魂笼手（本作第一视觉标识）

**这是整个游戏里最重要的一个模型部件。** 一个角色的视觉记忆点只能有一个，这就是那个。

| 项 | 设定 |
|---|---|
| 位置 | **左手**，从手背包到小臂中段（**不对称是重点**） |
| 材质 | **既不像金属也不像皮革**：像**湿的、有生长的甲壳**。黑紫底 + 沟槽状纹路 |
| 形状 | 覆盖手背与指节，指节处有细分节（**手指必须能动**——抓握与"吸魂"手势都靠它） |
| 自发光 | 沟槽内有微弱紫光。**全身唯一光源**，暗场里就是他的辨识点 |
| 接缝 | 与皮肤、袖口交界处**看不出接缝**——像长上去的，不是戴上去的 |
| 静止状态 | 几乎不发光（"初鸣"）→ 越用越亮（见 §6） |

## 6. 侵蚀三阶段的可视化（03 §2.5）

**同一个模型，三套材质/贴图。** 所以建模阶段就必须把
**笼手与左臂单独分出 UV 与材质槽**，否则后面做不了这套切换。

| 阶段 | 笼手 | 左臂 | 眼睛 | 触发 |
|---|---|---|---|---|
| **初鸣** | 沟槽内极弱紫光，几乎看不见 | 正常皮肤 | 正常 | 序章之后 |
| **共鸣** | 纹路**清晰浮现**并蔓延到手腕；紫光变亮 | 前臂出现暗色纹路，像淤青 | 光下眼底有一点紫 | 吞噬过 1~2 个精英/BOSS 魄 |
| **同化** | 纹路爬到**小臂中段以上**；紫光偏红；甲壳边缘开始"长" | 皮肤明显变色，血管可见 | **瞳孔开始变色**（暗处/特写可见） | 吞噬 ≥3 个，或深吸超阈值 |

> **纪律：三阶段的所有变化只集中在左臂与眼睛。身体其他部分不许变。**
> 玩家必须能靠"看一眼自己的左手"判断自己走到哪一步了。

---

## 7. 建模与绑定规格

| 项 | 要求 | 原因 |
|---|---|---|
| 三角面（MVP） | **≤ 25k** | 07：全程占位/低模，手感优先 |
| 三角面（最终） | ≤ 45k | |
| 骨骼 | **Mixamo 标准骨架**（约 65 骨）即可 | 07 §1.1：动作来自 Mixamo，别自造骨架 |
| **附加骨骼** | 笼手独立骨（手指 5 + 手腕 1）；刀、鞘各一根 | 手指要做"抓/吸"手势；鞘要单独摆动 |
| **材质槽必须分组** | `Body` / `Cloth` / `Metal(刀)` / `Gauntlet` / `Eye` | 侵蚀阶段靠换材质，不靠重建模型 |
| UV | **笼手与左臂单独一套 UV** | 侵蚀贴图只作用在这里 |
| 贴图 | 主体 2K；笼手 1K（可升 2K） | 笼手面积小但要看细节 |
| 动画 FPS | **导入时设 60** | 04 §12：全项目 60fps 基准，不允许 30 |
| 面部 | 不做面部骨骼，**表情靠贴图 + 姿态** | 低成本叙事（03 §10） |

> **绑定顺序提醒**：笼手与刀的骨骼要在**Mixamo 动画导入之前**就加好并蒙皮，
> 否则以后每次重定向都要重做一遍。

## 8. 与敌人的区分（07 §3.1：一眼能区分）

| | 主角 | 魔骸 | 精英 / BOSS |
|---|---|---|---|
| 主色 | 褪色蓝灰 + 土褐 | 黑 + 血红 | 黑紫 + 强发光 |
| 饱和度 | **低** | 高 | 高 |
| 轮廓 | 干净、瘦、直立 | 佝偻、抽搐 | 巨大、夸张 |
| 发光 | **只有笼手**，且弱 | 眼/伤口红 | 全身/武器紫 |
| 动态 | 有节奏 | 抖动、不自然 | 沉重 |

## 9. IP 禁区（03 §3）

**不要**参考或接近：

- 《鬼武者》系列主角的既有造型（含鬼之笼手的具体形态）
- 《只狼》狼的义手形态与兜/围巾搭配
- 任何带**红色义手 / 恶魔之手**的既有角色

**可以**使用战国浪人的通用元素：袴、绑腿、打刀、草鞋——这些属于历史公有领域（03 §3）。

> 差异化要点：
> **别人的"鬼手"是红的、帅的、成套的；
> 我们的笼手是紫黑的、湿的、像长上去的——而穿着它的人，衣服全是旧的。**
