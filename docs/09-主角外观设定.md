# 09 · 主角「丛云」外观设定（建模用）

> **⚠️ 2026-09-13 方向修正（制作人）**：主角**不再是日本浪人剑客**。
> 外观改为 **中国剑客 × 西幻剑客** 的混合：东方游侠的衣袍、交领与束发，
> 配上西方冒险者的皮胸甲、护肩、短斗篷与高筒皮靴。
>
> **世界、敌人、建筑仍然是和风**（魔骸足兵、道场、城下町不变）——
> 也就是说**他是这个世界的异乡人**，而这恰好和 03 §2.5 的人设一致：
> 一个无名的外来者，名字都是别人给的。
> 造型上"两边的衣服拼在一起、没有一件成套"不是设计事故，**是这句人设的视觉化**。
>
> 本文只讲**长什么样**。人设与剧情见 [03-剧情与关卡流程](03-剧情与关卡流程.md) §2.5。
> 目标读者：建模 / 绑定 / 材质。**和风版原文在 git 历史里**（本文件改写前的那一版）。

---

## 1. 一句话造型主题

> **他身上每一件东西都是别人给的、捡来的、改过的——只有那只手不是他的。**

这句话决定所有取舍：

- 衣服**不成套**（他没有家，没有人为他置办一身）——现在更强了：
  **连"哪一国"都不成套**，东方的袍子配西方的皮甲
- 剑**朴素、实用**（那是自己练出来的东西）——不是名剑，没有铭文、没有宝石
- **笼手是全场唯一一件"完整、精密、不属于人间"的物件**

造型上的一切对比都服务于这一句：**旧的、软的、灰的（人）** × **新的、硬的、紫黑的（笼手）**。

---

## 2. 剪影（第一优先级，比细节重要）

本作是 TPS 越肩视角，**玩家 90% 的时间在看他的背面**。
剪影必须回答三个问题：**朝哪边 / 在做什么 / 现在是什么状态。**

| 要求 | 做法 |
|---|---|
| 一眼看出朝向 | 右肩明显高于左肩（右手持剑的自然体态）；左臂略内收 |
| 一眼看出体型 | **偏瘦、筋瘦，不是健美**。肩窄、腰细、四肢结实但不粗 |
| 一眼看出是外来者 | **头上没有兜/笠/巾，身上没有家纹、没有门派徽记、没有成套甲胄**。头部轮廓干净，靠参差的束发与交领的破口做辨识 |
| 背面要有动态 | 一条**短斗篷（到腰）**＋ 斜挎的旧布带，带子上挂**陶酒壶与干粮布袋**（他全部的家当）。跑动时斗篷下摆飘动，是背面唯一的活跃元素 |
| 一眼看出状态 | 笼手的**自发光强度**是唯一的状态指示灯（见 §6） |

**身体比例**：身高 ≈ 175cm，头身比 ≈ 7.2。
**不要做成 8 头身的英雄比例**——他不是一个"看起来很能打"的人，是一个**看起来吃过苦的人**。

> ⚠️ **不对称是刻意的，而且是两处，互相呼应**：
> **右肩一片旧皮护肩**（那一侧他持剑，需要挡），
> **左臂从手背包到小臂中段的黑紫笼手**（那一侧什么护具都没有——那一侧不是护具，是别的东西）。
> 两处不对称各说各的话，剪影上左右一眼可分。

## 3. 配色板

整体低饱和（07 §7：暗黑、低饱和 + 血红/紫黑魔气、多为黄昏/雨夜）。
在雾和暗环境里**靠明度差与高光辨识，不靠贴图细节**。

| 部位 | 颜色 | Hex |
|---|---|---|
| 皮肤 | 低饱和黄褐（略脏） | `#B99A80` |
| 头发 | 近黑 | `#1B1A1C` |
| 内层中衣（交领右衽） | 旧亚麻灰白（脏） | `#C9C2B4` |
| 外层长袍 | 褪色墨青 | `#3E4A52` |
| 皮革胸甲 / 右肩护肩 | 旧皮革棕 | `#4A3E32` |
| 长裤 | 深褐 | `#3E372F` |
| 高筒皮靴 | 更深的旧皮革 | `#332B24` |
| 腰带 / 布绦 | 亚麻原色（脏） | `#8A7A4E` |
| 金属扣环（胸甲、腰带） | 素铁（无金、无宝石） | `#8A8578` |
| 短斗篷 | 灰蓝暗调 | `#2F3A40` |
| 剑鞘 | 黑漆（磨损） | `#241F1B` |
| 剑身剑脊 | 冷钢 | `#A8B0BB` |
| 剑身刃口 | 亮钢 | `#D8DEE6` |
| **笼手底** | 黑紫 | `#241C2E` |
| **笼手纹路** | 紫 + 自发光 | `#6B3E8C` / `#A855F7` |

### ⚠️ 配色纪律：**主角身上不许出现红色**

红色与紫黑是**魔骸与血**的专属色（07 §7）。
灰盒里主角当前的强调色是暗红（`0.55, 0.16, 0.14`）——**这会和敌人撞色，必须改**。

> **规则：暖色饱和的地方 = 敌人。**
> 主角身上只有低饱和的旧色 + 笼手的紫。玩家唯一一次在自己身上看到紫黑，就是笼手。

### ⚠️ 第二条：**不许出现金色与宝石**

西幻剑客最容易滑向"华丽的冒险者"——**他不是**。
他所有的金属件都是**素铁或旧铜**，扣环是功能性的，没有一个装饰。贵的是他练剑的时间，不是他的装备。

## 4. 逐部件

### 4.1 头部

- 头发：**自己剪的**，长度不齐、后颈有一撮没剪到。**束发**——用一根旧布带或一根素木簪在脑后束住，
  不是规整的发髻（他没有那个体面），也不披散。
- 脸：年轻（20 上下），**眼下有疲态**。
- **不要疤、不要异色瞳**——他的"非人感"全部交给笼手。
- 默认表情：**中性偏紧**（不是凶，是"不太会放松"）。
- ⚠️ **不要面具、不要斗笠、不要头巾、不要发冠**——那些是"身份"的符号，他没有身份。

### 4.2 上身（三层，别更多）

1. **中衣 / 交领右衽长袍**（内层，`#C9C2B4` 亚麻 + 外层 `#3E4A52` 墨青）：
   下摆到胯下，**袖子束到小臂中段**（束袖）——为了露出左臂的笼手。
2. **旧皮胸甲**（中层，`#4A3E32`）：只护胸腹一块，看得出来是自己拿皮子裁的、
   边缘不齐给它磨圆了；**只有右肩有一片护肩，左肩是空的**。
3. **短斗篷**（`#2F3A40`）：长度只到腰，**贴身、下摆不做长条飘动**（见下方规格警告）。

补充细节：**左臂的袖子明显比右边旧、也比右边短**（常年用右手，左手少动，而且要给笼手让位）。便宜，但有效。

### 4.3 下身

- 长裤（`#3E372F`），**束进靴筒**——因为要跑、要跳。
- **高筒旧皮靴**（`#332B24`），靴口有磨损的皮带扣。**不做金属护胫**（他买不起）。

### 4.4 武器：**直刃长剑**

> ⚠️ 这是相对旧版的一处**实质改动**：旧版是日本打刀（弯刃、单刃）。
> 新设定是**直刃双刃长剑**（中国剑的形制，尺寸克制）。

| 项 | 设定 |
|---|---|
| 类型 | **直刃双刃长剑**，实用、无铭、无装饰 |
| 尺寸 | **刃 ≈ 78cm / 柄 ≈ 20cm**（总长 ≈ 1m，**不是夸张的大剑**，也不是细刺剑） |
| 剑格 | 素铁，平直或极简，无纹 |
| 剑首 | 素铁，无宝石 |
| 剑鞘 | 黑漆磨损，**鞘尾有一圈后来补上的铜箍**（师父修的——这是这把剑唯一的故事） |
| 佩挂 | 腰左，**鞘会随动作摆动**（绑定要点） |

**不要做成名剑。** 双刃剑也更贴这个项目的战斗语义：**弹开与拼刀靠的是剑脊接招**，
而不是靠弯刀的拖割——这一点在动作设计上要一路贯彻。

### 4.5 背后

- 短斗篷（到腰）＋ 一条旧布带斜挎，挂：**陶酒壶**（缺了一角）+ **干粮布袋**。
- 这是他全部家当，也是背面剪影里唯一的活跃形状。

> ⚠️ **12 §6 第 3 条规格警告**：斗篷下摆、飘扬的发梢都是**薄片悬空结构**，
> 体素化时最容易糊掉或穿洞。所以斗篷**必须短、贴身、硬挺**，不做长条飘带；
> 真要做飘动，就在引擎里用骨骼/布料做，**不要烘进模型**。

## 5. ★ 噬魂笼手（本作第一视觉标识）

**这是整个游戏里最重要的一个模型部件。** 一个角色的视觉记忆点只能有一个，这就是那个。

| 项 | 设定 |
|---|---|
| 位置 | **左手**，从手背包到小臂中段（**不对称是重点**） |
| 材质 | **既不像金属也不像皮革**：像**湿的、有生长的甲壳**。黑紫底 + 沟槽状纹路 |
| 形状 | 覆盖手背与指节，指节处有细分节（**手指必须能动**——抓握与"吸魂"手势都靠它） |
| 自发光 | 沟槽内有微弱紫光。**全身唯一光源**，暗场里就是他的辨识点 |
| 接缝 | 与皮肤、袖口交界处**看不出接缝**——像长上去的，不是戴上去的 |
| 静止状态 | 几乎不发光（"初鸣"）→ 越用越亮（见 §6） |

> **它与"中国剑客 / 西幻剑客"都无关——这正是重点。**
> 衣服可以来自两个世界，**这只手哪儿都不来自**。

## 6. 侵蚀三阶段的可视化（03 §2.5）

**同一个模型，三套材质/贴图。** 所以建模阶段就必须把
**笼手与左臂单独分出 UV 与材质槽**，否则后面做不了这套切换。

| 阶段 | 笼手 | 左臂 | 眼睛 | 触发 |
|---|---|---|---|---|
| **初鸣** | 沟槽内极弱紫光，几乎看不见 | 正常皮肤 | 正常 | 序章之后 |
| **共鸣** | 纹路**清晰浮现**并蔓延到手腕；紫光变亮 | 前臂出现暗色纹路，像淤青 | 光下眼底有一点紫 | 吞噬过 1~2 个精英/BOSS 魄 |
| **同化** | 纹路爬到**小臂中段以上**；紫光偏红；甲壳边缘开始"长" | 皮肤明显变色，血管可见 | **瞳孔开始变色**（暗处/特写可见） | 吞噬 ≥3 个，或深吸超阈值 |

> **纪律：三阶段的所有变化只集中在左臂与眼睛。身体其他部分不许变。**
> 玩家必须能靠"看一眼自己的左手"判断自己走到哪一步了。

## 7. 建模与绑定规格

| 项 | 要求 | 原因 |
|---|---|---|
| 三角面（MVP） | **≤ 25k** | 07：全程占位/低模，手感优先 |
| 三角面（最终） | ≤ 45k | |
| 骨骼 | **Mixamo 标准骨架**（约 65 骨）即可 | 07 §1.1：动作来自 Mixamo，别自造骨架 |
| **附加骨骼** | 笼手独立骨（手指 5 + 手腕 1）；**剑、鞘各一根**；斗篷下摆可选 1~2 根 | 手指要做"抓/吸"手势；鞘要单独摆动 |
| **材质槽必须分组** | `Body` / `Cloth` / `Leather`(胸甲·护肩·靴) / `Metal`(剑) / `Gauntlet` / `Eye` | 侵蚀阶段靠换材质，不靠重建模型；`Leather` 是相对旧版新增的一组 |
| UV | **笼手与左臂单独一套 UV** | 侵蚀贴图只作用在这里 |
| 贴图 | 主体 2K；笼手 1K（可升 2K） | 笼手面积小但要看细节 |
| 动画 FPS | **导入时设 60** | 04 §12：全项目 60fps 基准，不允许 30 |
| 面部 | 不做面部骨骼，**表情靠贴图 + 姿态** | 低成本叙事（03 §10） |

> **绑定顺序提醒**：笼手、剑、鞘的骨骼要在**Mixamo 动画导入之前**就加好并蒙皮，
> 否则以后每次重定向都要重做一遍。

## 8. 与敌人的区分（07 §3.1：一眼能区分）

| | 主角 | 魔骸 | 精英 / BOSS |
|---|---|---|---|
| 主色 | 墨青 + 旧皮革 + 亚麻 | 黑 + 血红 | 黑紫 + 强发光 |
| 饱和度 | **低** | 高 | 高 |
| 轮廓 | 干净、瘦、直立、**衣袍+皮甲混搭** | 佝偻、抽搐、**和风甲胄** | 巨大、夸张 |
| 发光 | **只有笼手**，且弱 | 眼/伤口红 | 全身/武器紫 |
| 动态 | 有节奏 | 抖动、不自然 | 沉重 |

> **"他不是这个世界的"这件事，在这一张表里就已经成立了**：
> 满场都是和风的黑红魔物，站在中间的那个人穿着两个世界的旧衣服、只有一只手在发紫光。
> 玩家不需要被告知他是外来者——**看一眼就知道**。

## 9. IP 禁区（03 §3）

**不要**参考或接近：

- 《鬼武者》系列主角的既有造型（含鬼之笼手的具体形态）
- 《只狼》狼的义手形态与兜/围巾搭配
- 任何带**红色义手 / 恶魔之手**的既有角色
- **《巫师》杰洛特**的具体造型（双剑背身 + 狼徽 + 黑皮甲那套组合）
- **魂系**（《黑暗之魂》/《艾尔登法环》）的既有套装造型
- 《卧虎藏龙》等既有武侠片主角的具体造型

**可以**使用历史公有领域的通用元素：
交领右衽、束发、直刃长剑、皮甲、短斗篷、高筒靴、布绦——**这些都不属于任何一家**。

> 差异化要点：
> **别人的"鬼手"是红的、帅的、成套的；
> 我们的笼手是紫黑的、湿的、像长上去的——而穿着它的人，衣服全是旧的、还来自两个不同的地方。**

# 10. 同伴「绫」外观（02 §2.7 人设的视觉化）

> 人设与台词见 [03 §2.7](03-剧情与关卡流程.md)。本文只讲长什么样。

## 10.1 一句话

> **她比主角亮。**

丛云是全深色（墨青 + 旧皮革 + 亚麻），她**整体明度高一档**。
这不只是配色——它是"**她一笑，世界就稍微亮一点**"（03 §2.7）的视觉化。
在雨夜和体积雾里，明度差就是角色性质差。

## 10.2 配色板

| 部位 | 颜色 | Hex |
|---|---|---|
| 皮肤 | 干净（比丛云干净） | `#C4A88E` |
| 头发 | 深褐近黑，**束起**（行脚，不披散） | `#2A2320` |
| 内层（襦袢） | **旧白 / 亚麻（略脏）** | `#D8CFC0` |
| 外衣 / 腰带 | 苔绿 | `#5A6350` |
| 金属（铜铃、药囊扣） | 旧铜 | `#9A7B4F` |
| 药囊 / 木牌 | 皮革棕 + 木色 | `#6B543E` / `#7A6244` |

### ⚠️ 两条颜色禁区（与 09 §3、10 §1 同源）

- **不许出现红**（`#7A1418` 一类）——红是**魔骸与血**的专属
- **不许出现紫**（`#6B3E8C` 一类）——紫是**笼手**的专属，是她身上绝不能有的

> 于是她的识别色只剩**旧白 + 苔绿 + 铜**。干净、安静、不抢戏——
> 而且一眼就能从满场黑红里认出"这个是人"。

## 10.3 部件

- **年龄 20~25**，身高 ≈ **162cm**（比丛云矮一个头多一点）。
- 旅装：**多层但不华丽**。和丛云一样不是"成套"的新衣，但**没有他那么破**——
  她是行脚医，会照顾自己。
- **束袖**（行脚需要动手），不用长垂袖。
- 腰间三件（每件都有用，不是装饰）：
  1. **小药囊**（皮制，磨损）
  2. **铜铃**（辨位 / 习俗）
  3. **旧木牌**（行脚医的凭证——**同时也是她那个秘密的线索**）
- 背后：一个不大的行囊。**比丛云的轻**（她不带全部家当）。

## 10.4 ❌ 不要做的

巨乳 / 露腿 / 性感服装 / 二次元偶像式五官。

> 目标不是"加一个美女"，是"**给一个全是剑、血、魔骸和死亡的世界，放进去一个真正活着的人**"。
> 玩家第一次看到："这姑娘挺漂亮。"
> 玩了几小时之后："这角色怎么这么招人喜欢。"

## 10.5 建模与绑定规格

| 项 | 要求 | 原因 |
|---|---|---|
| 三角面 | **≤ 20k** | 她比主角简单（无笼手、无武器） |
| 骨骼 | **复用主角的 Mixamo 流程**（T24） | 别为 NPC 另起一套 |
| 材质槽 | 与主角**同分组命名**（`Body`/`Cloth`/`Metal`） | 统一光照与后处理 |
| **动画需求** | **只要 6 个左右**：`idle` / `walk` / `sit` / `hand_item`（递东西） / `treat`（处理伤口） / `talk` | **她从不进入战斗区域**（03 §2.7），所以**完全不需要战斗动画** |

> **成本提示**：她的动画量是主角的 1/5。**但这 6 个动作里有 4 个是"说话时的姿态"**——
> 因为她承担了全作最大的一部分对话，这些姿态的复用频率会非常高。**值得做细。**
