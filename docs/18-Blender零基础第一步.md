# 18 · Blender 零基础第一步（给人看的）

> 这份不是给 agent 看的（那在 [17](17-Blender与AI工具链.md)）。
> 这份是**给不熟悉 Blender 的人**看的：怎么打开、怎么看、怎么不把自己搞晕。
> 全程**只读着看也不会弄坏项目**——Blender 里怎么乱动都不影响仓库，除非你自己去"导出"覆盖文件。

## 0. 先记住一句话

**你现在只需要会三件事：打开、转着看、按空格看动画。** 别的都可以以后再说。

## 1. 怎么打开 Blender

三条路，从最省事到最麻烦：

| 方式 | 怎么做 |
|---|---|
| **① 桌面快捷方式**（推荐） | 双击桌面上的 **Blender 4.5**。看不到就往下看第 5 节 |
| **② 一键打开模型** | 双击 `G:\Game\tools\open_model_in_blender.bat`——它会**连模型和动画一起打开**，你什么都不用点 |
| **③ 手动** | 双击 `C:\Users\Gdy\Blender\blender-4.5.13-windows-x64\blender.exe` |

> 这是**免安装版**（zip 解压出来的），不需要管理员权限、也没写注册表。
> 想删掉它，直接删那个文件夹就行。

第一次打开会看到一个"启动画面"，中间有几个方块（那是新建工程的模板）。
**直接点别处或者按 Esc 关掉它**，我们要的是自己导入模型。

## 2. 界面认五个地方就够

打开后你会看到这样几块（不用记名字，知道"哪块是干嘛的"就行）：

```
┌──────────────┬───────────────────────────┬──────────────┐
│  左：工具栏   │      中间：3D 视口        │  右：大纲     │
│ （基本不用）  │   ← 你 90% 时间在这     │ （物体清单）  │
│              │                           ├──────────────┤
│              │                           │  右下：属性  │
│              │                           │ （改参数）    │
├──────────────┴───────────────────────────┴──────────────┤
│  底部：时间轴 ← 看动画就靠它                              │
└──────────────────────────────────────────────────────────┘
```

- **中间（3D 视口）**：模型在这、能转能看。
- **右上（大纲 / Outliner）**：列出场景里有什么东西。看模型的话会看到 `CongyunRig`（骨架）和 `geometry_0`（网格）。
- **底部（时间轴）**：一排数字帧。看到数字在 `1` 到 `30` 之间，就说明有动画。

## 3. 鼠标怎么用（新手第一道坎，务必看完）

这是唯一一个"不知道就完全动不了"的地方：

| 你想干嘛 | 操作 |
|---|---|
| **转着看** | 按住**鼠标中键**（滚轮按下去）拖动 |
| **平移** | `Shift` + 按住中键拖动 |
| **放大缩小** | 滚轮前后滚 |
| **框选/点选** | 左键点物体 |
| **调出菜单** | 右键（在视口里右键会弹一个小菜单） |

> **如果你鼠标没有中键**（比如笔记本触摸板）：
> 打开 `Edit → Preferences → Input`，勾上 **Emulate 3 Button Mouse**，
> 然后就可以用 `Alt + 左键` 代替中键。
>
> 转晕了、模型不见了：按 `Home` 键（把视野框回全部），
> 或把鼠标放在视口里按小键盘的 `.`（聚焦到选中的东西）。

## 4. 打开我刚做的模型（两种方式）

### 4.1 最省事：双击那个 .bat

双击 `G:\Game\tools\open_model_in_blender.bat`。

它会自动打开 Blender、导进绑定好的模型、把时间轴设好。**打开后直接跳到第 5 节。**

### 4.2 手动导入（想学的话）

1. 顶部菜单 `File` → `Import` → `glTF 2.0 (.glb/.gltf)`
2. 路径填 / 走到：`G:\Game\assets\models\model_player_congyun_03_textured.glb`
3. 点右下角 `Import glTF 2.0`
4. 如果模型太小/太大看不见：鼠标放视口里，按 `Home`

> 三个模型的区别：
> - `..._03.glb` —— 只有几何（一坨不会动的模型，用来重新绑骨的原始件）
> - `..._03_rigged.glb` —— **有骨架**，但还没贴图
> - `..._03_textured.glb` —— **有骨架 + 有材质（8 个槽）**，游戏里用的就是这一版
>
> ⚠️ 旧的 `..._02.glb` / `..._02_rigged.glb` **已删除**：那是丢头的废件
> （原因见 [13](13-本地3D生成流程.md) 的 `crop=center` 那一行）。

## 5. 看动画（这是你最想看的部分）

导入 `_rigged` 那个之后：

1. 看**底部时间轴**，如果数字范围是 `1` 到 `30`，那是走路（Walk）动作。
2. 鼠标**放在 3D 视口里**，按 **空格** —— 开始播放，再按一次停。
3. 想看另一个动作（挥砍）：在底部时间轴左边有个**动作名下拉框**（写着 `Walk`），点开选 **`Attack`**，再按空格。
   - 找不到那个框？把鼠标放在时间轴上，按 `N` 打开右侧小面板，也能切。

> ⚠️ 这两段动作是我用脚本生成的**粗胚**：能看出"腿在摆、刀在挥"，
> 但**不会好看**——袍子会跟着腿甩、腋下可能撕开。这是自动蒙皮的正常结果，
> 不是你看错了，也不是文件坏了。

## 6. 想动一动模型？（可选，玩坏了按 Ctrl+Z）

| 操作 | 键 |
|---|---|
| 选中 | 左键点它 |
| 移动 | `G`，然后动鼠标，左键确认 / 右键取消 |
| 旋转 | `R` |
| 缩放 | `S` |
| 撤销 | `Ctrl + Z` |
| 删除 | `X`（**别乱按**，删了也能 Ctrl+Z 回来） |

想只动某一个部位（比如抬起手臂）：先点骨架 `CongyunRig`，改成**姿态模式**（左上角下拉框从 `Object Mode` 选 `Pose Mode`），点一根骨头，按 `R` 转它。

> 记住：**这些改动只在你内存里**，不点导出就不会影响任何文件。

## 7. 想存下来 / 导出？（大多数时候你不需要）

- 存工程：`File → Save As`，存成 `.blend`（只在你自己机器上有意义）
- 导出模型：`File → Export → glTF 2.0`
  ⚠️ **导出时如果路径选到 `G:\Game\assets\models\` 里的同名文件，就会把项目里的替换掉**。
  不确定就先导到桌面看看。

## 8. 常见问题

| 现象 | 原因 / 怎么办 |
|---|---|
| 打开是一片灰，什么都没有 | 正常。启动画面那套东西被关掉了，你得先导入模型（第 4 节） |
| 模型看不见 | 按 `Home` 归位；或检查右上大纲里有没有 `geometry_0` |
| 按空格没反应 | 鼠标要**放在 3D 视口里**才有用，放在时间轴上不行 |
| 模型是灰的没有颜色 | **正常**——这个模型目前只有几何，没有贴图和 UV（还没做，属 T27） |
| 转动特别快/特别慢 | `Edit → Preferences → Navigation` 里调 Orbit Sensitivity |
| 界面被我拖乱了 | `File → Defaults → Load Factory Settings`（会重置成默认布局） |

## 9. 一句话总结你现在的目标

> **打开 → 空格看走路 → 切换成 Attack 再看一次 → 关掉。**
>
> 看完之后你要回答的问题只有一个：**"这样子的形变，能接受吗？"**
> 能接受，就让 agent 继续补动作；不能接受，就得先手绘权重（把袍子和腿分开）。
