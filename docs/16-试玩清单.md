# 16 · 试玩清单（5 分钟，照着走）

> **这份清单只为回答一个问题**（08 §5 / M1 的唯一验收标准）：
>
> # 「弹开成功的时候，你想不想再试一次？」
>
> 别的都可以含糊，这一条不行。**它只能由真人试出来**，而且它决定后面一切投入是否成立——
> 如果答案是不想，那 M5 的关卡铺量全是白做。

---

## 0. 跑之前（30 秒）

```powershell
git log --oneline -1        # 记下这个提交号，写进结论里
powershell -NoProfile -File tools\check.ps1    # 必须是 ALL CHECKS PASSED
```

然后**在编辑器里 F5 跑道场**（`scenes/levels/Dojo.tscn`）。无头模式看不到画面。

**别在别的 agent 正在写文件时跑**——`git status` 里如果有你不动过的 `M` 文件，
说明有人正在改，等它收工再玩（否则你玩的可能是半成品）。

---

## 1. 五步（每步只盯一件事）

| 步 | 做什么 | 屏幕上该看到什么 | 记什么 |
|---|---|---|---|
| **1** | 站着不动挨一刀 | 掉血、**架势槽涨** | 看不看得懂"我在被削架势"？ |
| **2** | 抬手弹开（右键，刀落下前那一下） | 火花 ＋ 音高 ＋ **架势槽 +18**（普攻只 +8） | 有没有"我抢到了"的感觉？ |
| **3** | 连按格挡，直到破防 | **破防和普通格挡要一眼能分清** | 分得清吗？还是只觉得自己卡住了？ |
| **4** | **成功弹开三次** | —— | **问自己：我想不想再来一次？** ← 这一条就是 M1 |
| **5** | 故意死一次 | 重开 ≤3 秒 | 重开之后想不想接着打？ |

---

## 2. 顺手试的三件事（各 30 秒，只记"有没有坏")

| 试什么 | 怎么试 | 出问题长什么样 |
|---|---|---|
| **重攻击（蓄力斩）** | **按住**左键不放 → 松开 | 按住之后什么都没发生 / 伤害和轻砍一样 / 卡住不动 |
| **跳跃** | 空格 | 跳不起来 / 跳起来镜头穿天花板 / 落地卡住 |
| **掉下平台** | 走出道场地板 | 一直往下掉**回不来**（那就说明 T45 那套在真场景里没生效） |

> 这三条是刚做进去的（T46 / T41 / T45），都有无头自检，但**自检查不出"手感"和"场景接线"**。

---

## 3. 结论只写三行（别写多）

```
提交号：
1. 通过 / 不通过
2. 第 4 步的原话（自己当时怎么想的，不要润色）
3. 最不舒服的那一处：哪个动作、哪个反馈、什么时候
```

**第 2 行是这份清单的全部意义。** 其余都是附注。

---

## 4. 如果没通过

**不许直接铺量。** 把"最不舒服的那一处"转成一张卡，**先修它**，修完回来重做第 4 步。

> 已经有过一次教训：连打防御的第一版修法**只测了一个点**，
> 结果错误的实现看起来完全正确（AGENTS.md §7 记着这件事）。
> 所以第 3 行要求写"什么时候"——**能定位到时刻的反馈才修得动。**
