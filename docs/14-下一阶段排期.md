## 1. 三条阻塞，按"卡住了多少东西"排序

### 阻塞 A：**姿势从哪来**没定 → 一次卡住 5 张卡

T38（动画覆盖）、T25（主角骨架）、T26（笼手）、T27（敌人）、T29（女主）
**全都在等同一样东西：动作从哪来。**

现状 `HumanoidAnimator` 只有 5 类姿势，而且是**直接手写骨骼旋转**。
要补到 07 §1.1 的 ~28 个，手写不可行。

三条候选：**程序化扩**（可控、零依赖、工时不可行）／**Cascadeur**（免费 indie，能出真动作，
但要建导入与帧对齐管线）／**CC0 动捕库**（最快，但 07 §1 已经判定剑术动作库不匹配）。

→ **建议：先打样 3 个动作验证管线，再决定要不要铺量。** 这正是 T24 的真正内容。

### 阻塞 B：**没有遭遇战编排** → "它还不是一个关卡"

现在能玩的本质是一个**道场沙盒**：`LevelBlockout` 按圆环刷 3 个敌人，
`Dojo` 里手摆了几个假人 + 一尊魔骸。**没有"遭遇区 → 触发 → 清场 → 推进"这条链**，
也没有存档点（03 §7 的鬼火）。

好消息：**T32 已经把地基铺好了**——L01 白盒里已经有 `combat_area` 组标记和 `Path` 路径点，
遭遇战可以直接挂在这些标记上。而且这条**不需要美术、不需要动画**，可以立刻开工。

### 阻塞 C：**M1 的验收从没做过** → 后面的投入都是赌注

M1 的唯一标准是 **"弹开成功时会想再试一次"**，只能由真人试出来。

现在条件其实**已经齐了**：架势槽能读（弹开 +18 vs 普攻 8）、弹开音高递增有了、
重开 ≤3 秒有了。该做一次**正式验收**，而不是零散试玩。
如果这条不成立，M5 的关卡铺量全是白做。

## 3. 一句话总结

**现在最该做的三件事：把简单档修好（T37）、把道场照亮（T40）、然后请真人回答一个问题——
"弹开之后，你想不想再来一次？"（T44）**

前两件是把眼前的试玩阻塞清掉；第三件决定后面两个月的投入是不是有意义的。
而**姿势来源（T24）和遭遇战编排（T42）是仅有的两条"能让别人解锁"的路**——
它们该在执行者空出来时立刻插进去，不必等 M1 验收的结论。
