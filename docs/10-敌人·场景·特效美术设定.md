# 10 · 敌人 / 场景 / 特效 美术设定

> 主角见 [09-主角外观设定](09-主角外观设定.md)。资产需求清单见 [07-资产清单与工具链](07-资产清单与工具链.md)。
> 本文只回答"**长什么样**"，给建模 / 特效 / 关卡美术用。

---

## 0. 一条压倒一切的约束

> **敌人必须让玩家看得出"它曾经是个人"。**

这不是美术口味，是**叙事要求**（03 §2.5 / §4.0）：

- 序章第三幕，魔骸首领会说一句人话——**"疼……"**
- 进入「共鸣」后，主角开始听见杂兵的片段——**"……别抢……这是给孩子的……"**

如果敌人做成一坨抽象的怪物，**这两处会完全失效**。
所以每一类魔骸都要保留**它生前身份的可读残迹**：足轻的阵笠、枪兵的长枪、武士的胴。

---

## 1. 魔骸通用设计语言

| 项 | 设定 |
|---|---|
| 主色 | **黑 + 血红**（`#141014` / `#7A1418`） |
| 发光 | 伤口与眼窝内**透出红光**（`#C8323A`）。**越强的敌人越亮** |
| 皮肤 | 灰黑、湿、无光泽；关节处**不自然地细长**（像被拉长过） |
| 轮廓 | **佝偻、不对称**；一侧手臂常比另一侧粗 |
| 动态 | **抽搐、卡顿**——动作本身是对的（还会用刀），但节奏是坏的 |
| 装备 | **残破但仍在用**：甲片掉了、绑绳断了，可它还在用那个姿势站着 |

**与主角的对比**（07 §3.1 要求"一眼能区分"）：

| | 主角（09） | 魔骸 |
|---|---|---|
| 主色 | 褪色蓝灰 + 土褐 | 黑 + 血红 |
| 饱和度 | **低** | 高 |
| 轮廓 | 干净、瘦、直立、对称 | 佝偻、不对称 |
| 发光 | **只有笼手**，且弱 | 伤口/眼窝，强 |
| 动态 | 有节奏 | 抽搐 |

> ⚠️ **这就是"主角身上不许出现红色"的原因**（09 §3）：玩家必须能在一瞬间靠颜色分辨"谁是人"。

## 2. 敌人类型

### 2.1 魔骸足兵（基础杂兵，最先做）

| 项 | 设定 |
|---|---|
| 生前 | 足轻 |
| 可读残迹 | **阵笠**（歪的、破的，但还戴着）+ 残破胴 + 一支断枪或打刀 |
| 体型 | 比主角略矮、略宽（他生前是个农夫兵） |
| 危险信号 | **唯一没有发光的地方是脸**——红光从阵笠的阴影里透出来 |
| 三角面 | MVP ≤ 12k，最终 ≤ 20k |

> **设计意图**：阵笠是它唯一还"整齐"的东西。玩家看久了会意识到——
> **它死前把笠戴正过。**

### 2.2 魔骸枪兵（危·突刺的载体）

| 项 | 设定 |
|---|---|
| 可读残迹 | 完整的长枪（**枪身完好**，因为枪不是它身体的一部分）+ 破损的具足 |
| 体型 | **瘦长、站得比别的魔骸直**——它还记得枪兵的姿势 |
| 危险信号 | 长枪尖端有**微弱的红光拖尾**（对应 02 §3 的「危」高音预警） |
| 三角面 | ≤ 12k / 20k |

> **设计意图**：它是所有魔骸里**姿势最"人"的一个**——因为它练枪练了一辈子。

### 2.3 精英 · 魔骸武士（第一章队长）

| 项 | 设定 |
|---|---|
| 可读残迹 | **一整套完整的旧武士盔甲**（不是残破的——它是精英，装备好） |
| 恐怖点 | **盔甲是好的，人已经不对了**。面颊（面具）下透出的红光、甲片缝隙里渗出的紫色 |
| 体型 | 比足兵高一个头；肩甲夸张但不对称 |
| 危险信号 | 全身紫黑 + 强发光（与主角的弱紫形成对比：**它已经走到头了**） |
| 三角面 | ≤ 20k / 35k |

> **设计意图**：它就是主角的**可见未来**（03 §2.5"每一个人都是主角可能成为的样子"）。
> 所以它的紫，和主角笼手的紫**必须是同一套颜色**——只是浓得多。

### 2.4 魔骸首领（序章，1.0 之后可复用为小 BOSS）

见 03 §4.0 第三幕。要点：

- **第一阶段"真的会正常打"** → 造型上必须**还像个人**（有完整甲胄、有姿态）
- **第二阶段吞噬尸体后** → 造型**实时变**：体型膨胀、甲片崩开、发光变强
- 说"疼……"的那一瞬间，**它的脸必须是可读的**——这是全序章最重要的一次特写

## 3. 场景

### 3.1 全局（07 §7 已定，这里只落成做法）

| 项 | 做法 |
|---|---|
| 时间 | **多为黄昏 / 雨夜**——统一色调，同时降低贴图精度要求 |
| 雾 | **体积雾**。它同时是氛围和"遮住远景低模"的省钱手段 |
| 光源 | **灯笼是唯一的暖色点**。数量要控制（暖色=注意力，多了会抢读招） |
| 材质 | 湿（石板、木）→ 高光反射，减少细节贴图需求 |

### 3.2 战斗区域的硬要求（03 §7，不可违反）

1. **背景必须低饱和、低对比**——敌人的黑红和主角的灰蓝要能跳出来
2. **不能贴墙打**：战斗区域要留出至少 8m×8m 的空地
3. **地面不能有高频图案**（碎石子、草叶）——会干扰判定距离的判断
4. **垂直元素要少**：柱子、栏杆会挡住读招

### 3.3 第一关：岐阜城下（M4）

| 区域 | 视觉要点 |
|---|---|
| 城下町 | 湿石板路 + 木质町屋；**门窗大多破着，但有几户还亮着灯**（幸存者） |
| 废弃神社 | 鸟居、石阶、积雪/落叶；**一个还没熄灭的香炉** |
| 地下水道 | 全暗，只有主角笼手与敌人伤口的光——**这里是最好的"笼手就是光源"的展示** |

## 4. 特效（07 §3.3 的落地）

**所有战斗特效都由 `EventBus.HitResolved` 驱动**——它已经带着 `Verdict` / `Damage` / `HitStopFrames`。
特效层只订阅事件，**不许反过来影响战斗逻辑**（04 §4 的订阅纪律）。

| 特效 | 触发 | 视觉 | 优先级 |
|---|---|---|---|
| **弹开火花** | `Verdict.Deflect` | 白蓝火花，从武器接触点向外**短促**喷射（8 帧内结束） | **P0** |
| **拼刀大颗粒火花** | `Verdict.Clash` | 更大、更慢、带拖尾的橙白火星 | **P0** |
| **命中血雾** | `Verdict.Hit` | 深红雾状，**方向与刀路一致**（不是爆开） | **P0** |
| **一闪黑白闪** | `Verdict.Issen` | 全屏 0.1s 高对比 + 血雾 + 拖尾 | **P0** |
| 体干破裂碎片 | `Verdict.GuardBreak` | 甲片/骨片飞散 | P1 |
| 魂火 | 击杀（已实现） | 黑紫自发光球（**已经做了**，M7 再美化） | ✅ 已有 |
| 危预警标记 | 敌人发动危招式（已实现） | 红闪（**已经做了**） | ✅ 已有 |
| 刀光轨迹 | 所有攻击 | `RibbonTrailMesh` 或自制，**只在大招上用** | P1 |

> ⚠️ **特效的第一原则是"不能盖住判定"**：
> 弹开与拼刀的火花必须**短**（≤8 帧），否则玩家看不清下一刀什么时候来。
> 华丽是二闪/忍杀的事，不是防御反馈的事。

## 5. 贴图与性能预算

| 项 | 预算 |
|---|---|
| 角色贴图 | 2K（主角）/ 1K（杂兵，可复用） |
| 场景材质 | 尽量**纯色 + 粗糙度变化**，少用大图 |
| 同屏三角面 | ≤ 150 万（07 §7） |
| 同屏敌人 | ≤ 8 |
| 掉帧降级顺序 | **① 体积雾 → ② 粒子数量 → ③ 同屏敌人数**（07 §7 已裁定） |

> 降级顺序里**没有"降分辨率"和"降帧率"**——60fps 优先于画面（01 §0 的精神）。
