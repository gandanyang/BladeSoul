# 01 · 设计总纲

## 1. 体验目标

用一句话说清楚玩家玩完之后的感受：

> "我一开始被杂兵砍死，后来能弹开一整套连招、拼刀赢下对攻、一闪连割三个人——
> 我能感觉到**我自己变强了**，而不是我的角色升级了。"

这是整个项目的北极星。所有设计 decision 都要回答一个问题：
**它有没有让"玩家变强"这件事变得更可感知？**

如果某个系统只是让数字变大（+10 攻击力），而没有改变玩家的操作方式，它就是本项目的低优先级。

### 三个必须成立的体验指标

| 指标 | 验收方式 | 目标值 |
|---|---|---|
| 弹开的反馈必须"上头" | 盲测：首次弹开成功后，玩家是否自发再试一次 | 90% 以上 |
| 手残玩家能通关 | 找一位不玩动作游戏的人，只教格挡+闪避+普攻 | 能打过第一个 BOSS（允许死 10 次以上） |
| 高手有空间 | 熟练玩家单场战斗弹开率 | 可达到 50%+，且明显区别于新手的 10% |

## 2. 核心循环

### 战斗内循环（秒级，最核心）

```
观察敌人前摇
   ↓
选择应对：闪避 / 格挡 / 弹开 / 拼刀 / 一闪
   ↓
获得反馈：顿帧 + 火花 + 音效 + 体干变化
   ↓
反打窗口：弹开→弹一闪 / 闪避→避一闪 / 拼刀→赢拼刀→忍杀
   ↓
体干打满 → 忍杀 → 吸魂 → 回到观察
```

**关键设计**：每一次"成功应对"都必须直接换来一个**进攻机会**。
只狼最爽的一点就是"防御不是挨打，防御是进攻的前置"。
如果我们的弹开只是"少掉点血"，那玩家没有理由去练它。

### 关卡内循环（分钟级）

```
探索区域 → 遭遇战（3~5 个敌人，考验走位与连锁一闪）
   → 拾取魂/道具 → 找到存档点（鬼火）→ 精英战 → BOSS 前存档 → BOSS
```

### 全局循环（小时级）

```
打不过 BOSS → 回头刷魂升级 / 解锁鬼力 → 变强 / 也更熟练 → 再战
```

注意：**"变强"必须同时来自数值和熟练度**。纯数值会毁掉动作游戏，
纯熟练度会劝退手残。两者都要有，且熟练度更重要（数值辅助只占 30% 权重）。

## 3. 三条通关路径（防劝退的核心架构）

这是本项目区别于"硬核只狼"的最重要设计。**任何一个 BOSS，都必须能被三条路径打死。**

### 路径 A：技巧流（高上限）
- 依赖：弹开、一闪、拼刀、连锁一闪
- 收益：战斗时长最短（BOSS 约 60~90 秒），体干压制，演出最华丽
- 风险：一次弹开失败 = 承受完整伤害 + 30 帧大后摇
- 谁选它：熟练玩家、想挑战评价的玩家

### 路径 B：基础流（低门槛，保底）
- 依赖：闪避（无敌帧）+ 普攻 + 格挡（兜底）
- 收益：不需要任何精准操作就能打完，BOSS 约 3~5 分钟
- 关键保证：**格挡掉体干不掉血，体干满了才破防受伤**
  - 这意味着手残玩家有"体干"这条血条挡在前面，而不是一击必死
  - 体干自动回复（且血量高时回复快），所以慢慢磨是可行的
- 谁选它：动作游戏新手、手残玩家、累了想稳过的玩家

### 路径 C：资源流（懒人路线）
- 依赖：魂收集换数值、鬼力元素魔法（远程消耗）、消耗道具（药、炸弹、符）
- 收益：不用近身也能磨血，BOSS 约 4~6 分钟但极稳
- 限制：鬼力槽有限，需要探索/刷魂补充，所以是"用探索时间换战斗难度"
- 谁选它：不喜欢搓招的玩家、卡关时的破局手段

**三条路径的平衡原则**：
- 技巧流收益最高，但**不唯一**
- 基础流永远可行，只是慢
- 资源流需要前置投入（探索/刷魂），所以允许它"作弊"一点

## 4. 目标玩家与难度预期

| 画像 | 期望 | 我们的承诺 |
|---|---|---|
| 玩过只狼/仁王/鬼武者 | 想要硬核手感，别太水 | 修罗难度弹开窗 6 帧，够硬 |
| 玩过鬼泣/战神但没玩过魂 | 想要酷炫战斗，不想被虐 | 武士难度是默认，宽松度接近只狼 |
| 动作游戏新手/手残 | 想体验剧情和帅气打斗 | 剑客难度 + DDA，保证能通关 |
| 完全不想练操作 | 只想看故事 | 见習难度 + 半自动防御，能走完全程 |

## 5. 视觉与美术方向

- **风格**：和风写实偏暗，参考《鬼武者》的暗黑战国 + 血红/紫黑魔气色调
- **降级策略**：手感优先。先用灰盒 + 免费低模资产（Mixamo 动画 + Quaternius 模型）
  把玩法跑通，美术替换放在 M7，**绝不允许美术阻塞手感开发**
- **镜头**：TPS 越肩视角，锁定目标时侧向偏移（能看到双方），战斗镜头轻微推拉
- **演出优先级**：一闪 > 忍杀 > 拼刀 > 弹开 > 普攻。一闪是全场最华丽的 1 秒

## 6. 音频方向（战斗手感的 50% 在这里）

- **弹开**：金属高频"叮——" + 短混响，音高随连击数递增（连弹越高音越尖，正反馈拉满）
- **拼刀**：低频"锵！"+ 金属摩擦尾音
- **一闪**：先 0.2 秒静音（世界抽真空）→ 血肉切割声 → 低频轰鸣
- **体干破裂**：木裂/骨裂的脆响 + 慢镜提示音
- **危（Perilous）攻击预警**：三类不同音高区分（详见 02 文档可及性部分）
- 所有音效必须在 M2 就用占位音频接上，**不允许"以后再加音效"**

## 7. 范围边界（明确不做的事）

| 不做 | 原因 |
|---|---|
| 开放世界 | 与"小游戏"定位冲突，成本爆炸 |
| 多武器切换 | MVP 只做一把太刀；多武器是 1.0 之后的扩展 |
| 联机/PVP | 帧数据同步成本极高，收益低 |
| 复杂技能树 | 只做「体/技/魂」三条线性升级 + 鬼力三元素解锁 |
| 全程配音与过场动画 | 用图文对话框 + 黑屏字卡 + 场景演出代替 |
| 装备/词条系统 | 分散玩家对"技术成长"的注意力 |
| 写实级美术 | 用占位资产，手感是唯一 KPI |

## 8. 风险与前提假设

| 风险 | 影响 | 应对 |
|---|---|---|
| 手感调参吃掉大部分工时 | 高 | 目标：40% 工时用于调参，从一开始就建调参工具 |
| 3D 角色动画资产短缺 | 高 | 用 Mixamo 自动绑骨 + 免费动捕，M1 就接入真实动画 |
| 一闪过强导致游戏退化成"猜拳" | 中 | 一闪仅对杂兵即死，对精英/BOSS 只削体干；且有失败大后摇 |
| 格挡太强导致没人练弹开 | 中 | 格挡有体干消耗和破防风险，弹开零消耗且给进攻窗口 |
| 三路径平衡失控 | 中 | 每条路径设"通关时长"基准，超出 2 倍就调 |

## 9. 成功标准

**M5 垂直切片成功标准（能给人玩）**：
- 一个新玩家不看说明，5 分钟内能学会格挡、10 分钟内能偶然成功弹开
- 一个熟练玩家能在 90 秒内用弹开+一闪打死第一个 BOSS
- 同一个人玩两次，第二次明显更轻松（证明熟练度在起作用）
- 连续玩 15 分钟不腻（说明核心循环成立）

**1.0 成功标准**：
- 2~3 小时可通关，有结局
- 挑战模式有排行榜（本地）或评价系统
- 通关后玩家会说"我想再打一遍打好看点"，而不是"终于结束了"
